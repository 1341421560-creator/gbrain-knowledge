# 【外部文档的规范化标题】

> **文档说明：** 本文由外部 Markdown 文档规范化整理而来。摘要和结构调整不代表对原作者观点的背书；事实使用前应结合来源和发布日期核验。

> **核心摘要：** 用 2～5 句话概括文档主题、主要结论、适用对象和时效边界，并自然包含以后可能搜索的核心关键词。

## 模板使用说明（生成成品时删除本节）

- 不得补写原文没有表达的事实；Codex 的解释、推断和评价必须单独标明。
- 保留原始标题、作者、发布方、来源链接、发布日期、导入日期和授权信息；未知内容明确写“未知”或“未提供”。
- 修复乱码、断行、重复标题和明显排版问题，但不得静默改变数字、代码、命令、引用和结论。
- 根据内容语义重组 `##` 和 `###` 标题，不按原文件的视觉样式机械切分。
- 标题和正文应保留原文关键术语、产品名、缩写及常用别名，方便 PGLite 检索。
- 长段落按观点拆分；步骤使用有序列表；并列事实使用无序列表；只有真正需要横向比较的数据才使用表格。
- 文档包含多个独立主题时，应拆分成多篇主题文档，并建立一篇来源总览页链接各子页面。
- 删除所有未使用章节、示例文字和 `【占位符】`。
