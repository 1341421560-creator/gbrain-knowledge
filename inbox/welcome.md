# GBrain 本地知识库

这是本地个人知识库的初始页面。

## 当前知识领域

- Amazon 运营
- 服务器与网络安全

## 使用约定

- 长期有效的知识保存为 Markdown 文件。
- 每篇知识尽量注明标题、日期、来源和领域。
- 密码、API 密钥、SSH 私钥和访问令牌不存入知识库。
- PGLite 数据库只作为检索索引，Markdown 文件是可阅读、可备份的知识原稿。
