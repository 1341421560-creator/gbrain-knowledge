<a id="brand-constraints"></a>
## 1. 品牌视觉约束与风格锁定

品牌视觉规范至少包含：

| 维度 | 固定内容 | 需要记录的细节 |
|---|---|---|
| Logo | 主标、反白版、图标版 | 最小尺寸、安全区、允许位置、禁用变形 |
| 色彩 | 主色、辅色、强调色、中性色 | 色值、使用比例、背景与文字对比 |
| 字体 | 标题、正文、数字、外语 | 字体家族、字重、字号层级、行距 |
| 构图 | 主体位置、占比、留白 | 常用画布、视觉流、文案安全区 |
| 光影 | 主光、对比、色温 | 高调/低调、轮廓光、阴影风格 |
| 材质 | 常见背景和道具 | 粗糙度、反射、纹理、禁用材质 |
| 摄影 | 机位、焦段感、景深 | 主图、场景图、细节图的固定语法 |
| 图形 | 圆角、线条、图标、纹样 | 尺寸、粗细、重复方式 |
| 文案 | 语气、大小写、数字和标点 | 标题长度、禁用词、术语表 |
| 禁用项 | 不应出现的视觉和内容 | 未授权色彩、字体、效果、功效或认证 |

品牌锁定提示词：

~~~text
本次图像必须遵循以下品牌视觉规范：
主色：[色名与色值]，辅色：[色名与色值]，强调色：[色名与色值]；不要引入规范外的高饱和颜色。
Logo：使用提供的 Logo 原文件，保持形状、比例、颜色和安全区，不重绘、不倾斜、不加立体效果。
构图：商品位于 [位置]，占画面 [比例]；[位置] 保留文案安全区。
光影：[固定主光方向、软硬、对比和色温]。
材质与背景：[固定材质、纹理和反射]。
字体与排版：[标题/正文字体风格、对齐和层级]。
禁用：[列出不允许的装饰、色彩、滤镜、图形和文案]。
除本次变量 [场景/商品/颜色] 外，其余品牌视觉规则保持一致。
~~~

品牌色不能只写“蓝色”。应提供标准色值和允许的明暗范围，并说明它作用于背景、文字、装饰还是光效。AI 输出颜色可能受光照和色彩管理影响，最终文件应由人工用标准色板校正。

<a id="asset-system"></a>
## 2. 电商视觉资产系统

不要孤立生成单张图。先建立资产地图：

| 资产 | 目的 | 关键内容 | 常见风险 |
|---|---|---|---|
| 商品主图 | 识别和合规 | 商品完整、背景干净、结构准确 | 变形、错字、边缘问题 |
| 场景图 | 展示使用情境 | 用户、环境、尺度、动作 | 功能虚构、人物抢主体 |
| 卖点图 | 解释功能 | 一个卖点、一个证据、清晰层级 | 信息堆叠、证据不足 |
| 细节图 | 展示材质和工艺 | 微距、纹理、接口、缝线 | 假细节、过度锐化 |
| 尺寸图 | 解释大小 | 真实数据、参照、标注 | AI 比例误导 |
| 对比图 | 区分方案或版本 | 同一条件、明确维度 | 贬损、不可证实比较 |
| 包装图 | 展示开箱和品牌 | 包装结构、印刷、配件 | 漏件、错字、工艺虚构 |
| 系列图 | 建立品牌一致性 | 色板、构图、光影、角色 | 每张风格漂移 |
| 社媒图 | 抓注意和传播 | 单一主题、强视觉钩子 | 牺牲商品真实性 |
| 广告变体 | 测试增长假设 | 只改变一个变量 | 多变量无法归因 |

“黄金基准”由用户原始产品参考、已确认的产品事实和视觉规范组成：

1. 选择结构清楚的用户原始图，标明各张参考职责。
2. 整理准确的文字、Logo、颜色和不可变结构。
3. 保存固定商品描述、禁改项和用户批准的视觉规范。
4. 生成的样图可用于人工比对与质量检查；后续生图默认仍输入用户原始参考。
5. 只有用户明确指定某张生成图作为修改对象时，才允许以该图为输入，不自动沿用生成结果反复迭代。

<a id="modular-content"></a>
## 3. 模块化详情页与信息层级

主图、附图和 A+ 的实际生产先执行[完整规划人工确认](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-3)。以下模块表用于组织候选方案；将内容补全为[分镜与图文审阅卡](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-4)并在对话中展示后，再进入生图。

平台模块和尺寸会变化，制作前需核对当前规范。通用信息层级可以分为：

1. **首屏主视觉：** 产品是谁、核心价值是什么。
2. **生活方式场景：** 谁在什么情况下使用，解决什么问题。
3. **核心功能特写：** 用真实细节和证据解释关键卖点。
4. **快速优势网格：** 3～5 个可扫描的独立优势。
5. **深度解析：** 结构、成分、步骤、配件或工作原理。
6. **尺寸与适配：** 真实尺寸、兼容关系和使用边界。
7. **生态与组合：** 关联产品、套装或完整使用流程。
8. **信任与说明：** 真实认证、质保、材料和注意事项。

模块设计表：

| 模块 | 画面 | 文案 | 验收 |
|---|---|---|---|
| 主视觉 | 商品主导、构图简洁、品牌识别 | 一句核心价值 + 必要副标题 | 3 秒内理解产品和定位 |
| 场景 | 真实用户和环境、动作明确 | 痛点或收益 | 商品可见，动作符合功能 |
| 特写 | 微距或交互部位 | 一个可验证的卖点 | 细节来自真实商品 |
| 优势网格 | 等宽卡片或图标 | 每格一个优势 | 移动端可扫读 |
| 深度解析 | 分屏、步骤或爆炸示意 | 原理、步骤或成分 | 不制造内部结构 |
| 生态组合 | 多产品有明确关系 | 搭配用途 | 规格、数量和兼容性准确 |

详情页任务指令：

~~~text
为 [品牌] 的 [产品] 规划一套模块化电商详情视觉。目标受众：[用户]；核心问题：[痛点]；核心卖点：[已核验卖点 1、2、3]；品牌风格：[风格规范]。

逐模块输出：
1. 模块目的
2. 画面内容和构图
3. 商品、人物、道具的空间关系
4. 光影、材质和品牌色
5. 标题、副标题和正文占位
6. 移动端裁切与文字安全区
7. 必须锁定的商品事实
8. 人工验收项目

不要编造尺寸、数据、认证、对比结论或产品功效。
~~~

<a id="visual-psychology"></a>
## 4. 视觉心理与卖点表达

视觉不是装饰，应服务于信息和行为目标：

- **视觉层级：** 商品、标题、证据、行动信息按优先级排列。
- **图形—背景分离：** 通过明度、色彩、轮廓光和留白突出主体。
- **阅读路径：** 使用 Z 形、F 形、中心聚焦或顺序步骤，引导从价值到证据。
- **接近性：** 把图标、标题和说明放在一起，避免对应关系不明。
- **相似性：** 同类卖点使用统一卡片、图标和颜色。
- **对比：** 用大小、明暗和粗细突出重点，不依赖过多装饰。
- **认知负荷：** 一张图尽量表达一个主要信息。
- **真实性：** 使用真实商品、真实动作和可验证证据建立信任。
- **移动优先：** 缩小后仍能看清商品、标题和关键数字。

卖点转视觉方法：

| 卖点类型 | 视觉证据 | 不可靠做法 |
|---|---|---|
| 小巧便携 | 与真实参照物同平面展示 | 任意缩小手或环境 |
| 材质耐用 | 真实材质微距、结构和测试证据 | 只加火花、盾牌等夸张符号 |
| 易操作 | 手部动作或 1-2-3 步骤 | 同时展示过多功能 |
| 舒适 | 人体工学接触点和自然姿态 | 只使用“幸福表情” |
| 容量 | 真实数量和尺寸数据 | 让商品内部无限扩大 |
| 防水/性能 | 经确认的等级、测试或使用边界 | 生成未证实的极端场景 |
| 环保 | 经核验的材料和认证 | 仅加树叶、绿色背景就宣称环保 |

<a id="text-layout"></a>
## 5. 图像内文字与排版控制

图像模型的文字能力差异很大。商业交付优先采用“AI 生成底图 + 设计工具排版”的稳妥流程。若使用原生文字渲染，必须逐字验收。

文字任务五项：

1. **精确文案：** 用引号逐字给出，不允许改写。
2. **语言与字符：** 中文、英文、数字、大小写、标点和换行。
3. **层级：** 标题、副标题、正文、数字和按钮。
4. **位置和对齐：** 左上、居中、右对齐、文本框宽度和安全区。
5. **字体风格：** 无衬线、衬线、几何、手写等；品牌字体应提供授权文件并后期排版。

模板：

~~~text
在画面 [位置] 放置以下文字，必须逐字一致，不翻译、不改写、不增删：
标题：“[精确标题]”
副标题：“[精确副标题]”
数字：“[精确数字与单位]”
按钮：“[精确按钮文字]”

排版：标题为 [风格、粗细]，副标题为 [风格]，左对齐，行距 [描述]，文本框宽度不超过画面 [比例]。文字与背景保持足够对比，并位于安全区内，不遮挡商品、人物面部或关键卖点。不要生成任何未提供的额外文字。
~~~

翻译现有图片文字：

~~~text
识别图中 [位置] 的源语言文字，先在文本中列出识别结果和目标语言译文供人工确认；确认后只替换该文字区域。保持原有层级、位置、对齐、字号比例、颜色和背景不变。不要修改 Logo、型号、专有名词和未授权区域。
~~~

稳妥流程：

1. OCR/人工抄录原文。
2. 校对原文、译文、数字、单位和术语。
3. 生成无文字或带占位框的底图。
4. 在设计工具中排版真实字体。
5. 做语言、法务和移动端可读性验收。

<a id="packaging-materials"></a>
## 6. 包装材质与工艺描述词

包装描述公式：

~~~text
包装结构 + 基材和厚度感 + 表面覆膜 + 印刷工艺 + 局部工艺 + 开合方式 + 边缘与折线 + 摄影光影
~~~

| 类别 | 描述词 |
|---|---|
| 结构 | 折叠纸盒、天地盖、抽屉盒、磁吸翻盖盒、软袋、瓶、罐 |
| 纸材 | 白卡、黑卡、牛皮纸、纹理纸、瓦楞、刚性厚纸板 |
| 表面 | 哑光覆膜、触感膜、亮膜、未涂布纸、细纹理 |
| 金属工艺 | 烫金、烫银、玫瑰金箔、镭射箔 |
| 凹凸 | 击凸、压凹、深浮雕、盲压 |
| 光泽 | 局部 UV、高光清漆、哑光清漆 |
| 印刷 | 专色、四色印刷、丝网、白墨、金属墨 |
| 细节 | 磁吸闭合、丝带拉手、模切窗口、内托、封口贴 |
| 边缘 | 折线清晰、包边、纸板厚度、转角、开合缝 |
| 摄影 | 柔和轮廓光、受控镜面高光、真实纸纤维和阴影 |

包装模板：

~~~text
创建 [产品] 的 [包装结构] 概念图。基材为 [纸板/玻璃/金属/塑料]，表面为 [哑光覆膜/触感膜/未涂布纹理]；Logo 使用 [烫金/击凸/压凹/局部 UV]，具体位置为 [位置]。盒体厚度、折线、转角、开合缝、内托和边缘结构真实。

使用专业棚拍柔光和窄轮廓光，显示纸纤维、箔面反射、浮雕高度和局部光泽差异。包装上的所有文字使用提供的最终文案，无法准确生成时留出排版区域，不编造产品信息。
~~~

工艺避免事项：

- 不要同时堆叠过多工艺，除非真实生产方案支持。
- “600gsm、1mm 击凸”等数值必须来自设计或供应链规格，不能当装饰词。
- 箔面、局部 UV 和哑光覆膜要有不同的反射逻辑。
- 包装概念图不等于可生产刀模；量产前必须由结构和印刷供应商校核。

<a id="canvas-extension"></a>
## 7. 画布扩展与版式适配

扩图用于同一主视觉适配不同版位：

~~~text
把原图从 [原比例] 扩展到 [目标比例]，原主体的位置、大小、身份、结构、服装、商品、光线和颜色保持不变。只向 [方向] 延展 [背景内容]，延续原有透视、纹理、光照梯度、景深和噪声。在 [位置] 创建干净负空间供后期排版，不新增人物、商品、Logo 或文字。
~~~

品牌版式适配流程：

1. 从用户原始图或用户明确指定的编辑目标开始，遵守[原始参考与提示词规则](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-5)。
2. 列出每个渠道的当前比例和安全区。
3. 确定主体是否固定位置或允许小幅平移。
4. 只延展背景，不缩放变形商品。
5. 为文字预留干净区域，文字后期排版。
6. 分别验收桌面端、移动端和裁切预览。

不要用扩图掩盖原图主体过小或结构错误。主体问题应先在基准图修复，再做版式适配。

<a id="pattern-development"></a>
## 8. 花型、纹样与新品概念

图案描述维度：

~~~text
主题元素 + 绘制风格 + 单元尺寸 + 密度 + 排列 + 重复方式 + 方向性 + 色板 + 背景 + 应用材质
~~~

主题示例：

- 自然：花卉、叶片、海洋生物、山水、果实。
- 几何：条纹、圆点、格子、波纹、抽象形。
- 传统和文化：只在理解来源并获授权时使用，避免无语境挪用。
- 趣味：动物、食物、字母、玩具和图标。
- 季节：春季新叶、夏季海洋、秋季果实、冬季雪花和松枝。

重复方式：

- straight repeat：平接重复。
- half-drop repeat：半落重复。
- brick repeat：砖式重复。
- mirror repeat：镜像重复。
- tossed pattern：散点式。
- directional / non-directional：有方向或无方向。
- seamless tile：无缝连续单元。

花型模板：

~~~text
设计一款可无缝重复的 [主题] 图案，元素包括 [元素 1、2、3]，采用 [绘制风格]。单元大小 [小/中/大]，密度 [低/中/高]，使用 [重复方式]，接缝处连续且不出现明显条带或重复热点。色板限定为 [颜色与色值]，背景为 [颜色]。应用于 [面料/包装/壁纸] 时，考虑材质纹理和实际印刷尺度。输出独立平铺单元和应用效果图。
~~~

迭代方式：

1. 第一轮只确定主题、元素和重复结构。
2. 第二轮只改变色板。
3. 第三轮只改变密度、尺度或方向。
4. 第四轮加入一个新元素或移除一个旧元素。
5. 保存每轮变量，避免无法判断哪个改动有效。
6. 最终无缝性、色彩和印刷文件需要专业工具校验。

<a id="growth-experiments"></a>
## 9. 增长实验与指标

AI 可以降低变体成本，但不能替代实验设计。一次实验只改变一个主变量：

| 假设 | 变量示例 | 固定项 |
|---|---|---|
| 更近的商品特写提高点击 | 商品占比 | 文案、背景、价格、受众 |
| 生活方式图提升理解 | 主图类型 | 卖点、色板、版位 |
| 暖色光更适合礼赠 | 光影色温 | 构图、商品、文案 |
| 人物互动提高代入 | 是否有人物 | 商品位置、场景、标题 |
| 卖点数字更醒目 | 数字层级 | 其他文案、画面和渠道 |

实验记录：

~~~text
实验 ID：
业务目标：
目标受众：
渠道与版位：
假设：
唯一变量：
固定项：
A 版本：
B 版本：
主要指标：
护栏指标：
样本周期与流量：
结果：
是否可推广：
可能混杂因素：
~~~

常见指标包括点击率、转化率、停留、滚动深度、加购和退货反馈。指标含义和归因能力取决于平台，应结合真实数据，不从图像审美直接推断增长。

## 10. 提示词模板库

每个模板必须包含：

| 字段 | 内容 |
|---|---|
| 模板名称 | 团队能够快速理解的任务名称 |
| 适用场景 | 主图、场景图、海报、包装、花型等 |
| 业务目标 | 这张图要解决什么问题 |
| 必填输入 | 商品图、文案、Logo、色板、比例 |
| 参考图职责 | 每张图提供什么，不提供什么 |
| 可变字段 | 场景、颜色、人物、版式等 |
| 固定约束 | 商品事实、品牌规范和禁用项 |
| 完整模板 | 带变量占位符的可执行指令 |
| 示例 | 一个已验证的填写结果 |
| 验收标准 | 结构、文字、品牌、渠道、合规 |
| 版本信息 | 版本、模型、日期、负责人、变更记录 |
| 实验表现 | 使用次数、通过率、常见失败和适用边界 |

通用结构：

~~~text
【模板名称】

【业务目标】
【输入职责】
【主体事实】
【内容与空间关系】
【视觉设计：构图、光影、材质、风格】

【输出规格】
【固定约束】
【禁用项】
【验收标准】
【失败修正】
~~~

模板不是越长越专业。可变字段与固定约束必须清楚分开，团队成员只填写变量，不随意改动品牌硬约束。Listing 主图与 A+ 的模板必须绑定已批准的分镜版本，按[知识库检索与提示词整理](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-5)执行。

<a id="team-general-duties"></a>
### 11.2 通用团队职责与检查事项

以下是品牌生产的职责检查；Listing 主图与 A+ 的执行顺序和人工确认以独立的[九步流程](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-2)及[确认节点](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-3)为准。

1. **需求单：** 确认用途、受众、渠道、版位、卖点、截止时间、负责人和审批人。
2. **事实核验：** 商品结构、尺寸、颜色、材质、功能、认证和文案由业务方确认。
3. **授权检查：** 商品图、Logo、字体、人物、参考图和品牌元素拥有使用权。
4. **输入检查：** 图片清晰、多角度和细节齐全，文件命名统一。
5. **任务拆解：** 选择文生图、图生图、局部编辑、扩图、排版或批量变体。
6. **模板调用：** 选择已验证模板，只填写变量，不改固定约束。
7. **小批测试：** 先生成少量候选，判断方向和主要失败。
8. **单变量迭代：** 每轮只改一个关键变量，记录修正指令。
9. **选片评分：** 按统一评分表选择，记录淘汰原因。
10. **专业后期：** 文字、Logo、颜色、边缘和合成细节进入设计流程。
11. **业务验收：** 商品、品牌、平台和合规负责人分别检查。
12. **多端预览：** 验证桌面、移动、裁切和压缩后的表现。
13. **归档：** 保存输入、模板版本、提示词、参数、结果、最终文件和实验数据。
14. **复盘：** 把成功条件和失败模式更新回模板库。

角色分工：

| 角色 | 责任 |
|---|---|
| 需求方 | 提供目标、卖点、受众和真实商品数据 |
| 设计/生成 | 选择工作流、构图、光影和提示词 |
| 品牌 | 检查 VI、Logo、色板、字体和语气 |
| 商品/法务 | 检查事实、功效、认证、授权和风险 |
| 增长 | 定义实验假设、指标和流量 |
| 归档负责人 | 维护模板版本、文件和经验记录 |

<a id="compliance"></a>
## 13. 版权、肖像与商业合规

- 商品功能、尺寸、材料、认证、对比、评价和效果必须可验证。
- 不制造不存在的接口、配件、容量、成分或使用效果。
- 真实人物、换脸、声音和肖像需获得适用授权。
- Logo、字体、摄影图、插画、纹样和竞争对手素材需确认权利。
- 学习参考图的构图和视觉方法时，避免复制独特角色、商标、受保护图形和可识别作品细节。
- 医疗、儿童、安全、食品、化妆品和性能类内容需增加专业审查。
- 不把生成图直接当作可生产包装刀模、结构图、检测报告或认证证明。
- 平台比例、主图、文字、价格和促销规则具有时效性，发布前查当前官方规则。
- 对外使用时，根据业务和地区要求标记合成内容。

<a id="failure-correction"></a>
## 14. 常见失败与修正

| 问题 | 原因 | 修正 |
|---|---|---|
| 未展示分镜就直接生图 | 把一般任务授权当作规划批准 | 回到[人工确认节点](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-3)，展示整体风格、全部分镜、画面与文案。 |
| 用户否定镜头仍反复生成 | 把设计问题误当成随机生成问题 | 按[镜头重设计](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-6)修改景别、动作、空间或叙事，重新确认后再写提示词。 |
| 长页零间距仍明显割裂 | 只检查拼接，没有规划上下场景 | 按[连续性验收](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-7)重做相邻边缘和构图过渡。 |
| 每张图品牌感不同 | 规范只有抽象形容词 | 固定色值、构图、光位、字体层级和禁用项。 |
| Logo 变形 | 让模型重绘 Logo | 使用原始 Logo 后期叠加，并锁定安全区。 |
| 详情页太杂 | 每张图表达多个卖点 | 一模块一个主要信息，建立清晰层级。 |
| 移动端看不清 | 只按桌面设计 | 先做移动端裁切和字号预览。 |
| 文字错字 | 依赖一次生成 | 逐字校对，商业稿优先后期排版。 |
| 包装工艺不真实 | 堆叠大量“高级”工艺 | 按真实生产方案选择基材、覆膜和局部工艺。 |
| 花型接缝明显 | 没定义重复方式 | 指定无缝单元、重复类型并用专业工具检查。 |
| 扩图复制人物或商品 | 未限制扩展区 | 只延展背景，明确不新增主体。 |
| A/B 测试无法归因 | 同时改了多个变量 | 固定其余项，只改变一个主变量。 |
| 模板越用越差 | 无版本和复盘 | 记录模型、样本、通过率、失败和回退点。 |
| 视觉承诺过度 | 用氛围替代证据 | 只展示已验证卖点和真实使用边界。 |
