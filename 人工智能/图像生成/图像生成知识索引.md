<a id="scope"></a>
## 1. 适用范围

- 适用于文生图、图生图、元素替换、添加或删除、局部重绘、扩图、换背景、换色、换材质、商品场景合成、人物换装、包装概念和批量视觉生产。
- 不绑定特定模型、平台或供应商。是否支持负向提示词、种子、参考权重、结构控制、蒙版、多图输入和原生高清输出，需要按实际工具确认。
- 电商图是主要实践场景，方法也适用于海报、社交媒体、品牌视觉、人物摄影和内容配图。
- 商业交付必须人工检查商品事实、文字、Logo、品牌、授权和目标平台当前规则。

<a id="capability-map"></a>
## 2. 能力地图

| 能力 | 典型输入 | 目标 | 最关键约束 |
|---|---|---|---|
| 文生图 | 文字描述 | 从零生成画面 | 主体、构图、光影、风格 |
| 图生图 | 参考图 + 文字 | 保留部分视觉事实并重绘 | 参考优先级、变化范围 |
| 元素替换 | 原图 + 可选目标参考图 | 用新元素代替旧元素 | 定位、几何继承、环境锚定 |
| 局部编辑 | 原图 + 蒙版/区域描述 | 只修改指定区域 | 未编辑区域必须锁定 |
| 扩图 | 原图 + 新画布比例 | 延展背景或构图 | 透视、光源、纹理连续 |
| 多图融合 | 多张参考图 | 合并主体、场景或风格 | 每张图职责和冲突优先级 |
| 批量变体 | 基准图 + 变量表 | 生成 SKU、场景或版式系列 | 一次只变一个主变量 |
| 高清与修复 | 已选结果图 | 放大、去瑕疵、恢复细节 | 不新增虚假纹理和错字 |
| 品牌化生产 | 商品资产 + VI + 模板 | 批量一致输出 | 品牌硬约束、版本和验收 |

<a id="learning-path"></a>
## 3. 学习路径

1. 先学任务拆解、提示词结构、描述词、参考图分工和局部编辑边界。
2. 再掌握任意元素替换、添加、删除、换色、换材质、换背景和白底图。
3. 学习光位、阴影、构图、尺寸参照、场景融合、SKU 和九宫格选片。
4. 学习玻璃、金属、织物、皮革、多对象、空间介词、景深和复杂材质。
5. 学习人物换装、身份锁定、多参考图融合和系列一致性。
6. 最后建立品牌视觉、详情模块、文字排版、包装、花型、实验、模板库和团队 SOP。

<a id="decision-flow"></a>
## 4. 任务决策流程

**Listing 主图、附图与 A+ 先走人工确认流程。** 所有产品都先在对话中展示整体风格、分镜、画面规划和图文内容；规划通过后生成代表样图，样图通过后批量制作。合并指南的图像章节：[Listing 主图与 A+ 图片制作流程](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visuals)。执行入口：[九步完整流程](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-2)、[两个确认节点](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-3)。用户否定镜头时，按[镜头重设计](../../电商运营/亚马逊/listing/flipcase完整listing指南.md#visual-6)返回规划；普通生成偏差按纠错路径处理。完整定义统一在合并指南的图像章节维护。

~~~text
是否已有必须保持一致的主体？
├─ 否 → 文生图：先定义主体事实，再设计画面
└─ 是 → 是否只改局部？
   ├─ 是 → 局部编辑：定位目标、定义编辑区和锁定区
   └─ 否 → 图生图/多图融合：为每张参考图指定职责和优先级

是否用新元素替换旧元素？
├─ 是 → 语义选择 → 目标注入 → 几何继承 → 环境锚定 → 边缘验收
└─ 否 → 按添加、删除、换色、换材质、换背景或扩图执行

是否要求系列一致？
├─ 否 → 单图优化与验收
└─ 是 → 固定用户原始参考、主体卡、已批准视觉规范、模板和版本记录
~~~

<a id="prompt-formula"></a>
## 5. 通用提示词公式

完整公式：

~~~text
任务动作 + 目标定位 + 主体事实 + 环境场景 + 空间与构图 + 光影系统 + 材质表现 + 风格与镜头 + 输出规格 + 不可变约束 + 验收要求
~~~

局部编辑：

~~~text
只修改 [精确位置和元素] 为 [目标状态]；保持 [主体身份、结构、比例、Logo、文字、材质、光线、构图、背景] 中未授权的部分不变；匹配原图的透视、遮挡、阴影、反射、景深和边缘。
~~~

元素替换：

~~~text
定位旧元素 + 注入新元素事实 + 继承位置/尺度/角度/透视/遮挡 + 匹配光影与环境 + 锁定未编辑区 + 边缘验收
~~~

SKU 换色：

~~~text
目标颜色 + 颜色区域边界 + 材质锁定 + 原有光影继承 + 其他区域不变
~~~

<a id="quality-framework"></a>
## 7. 质量评估框架

建议每张候选图按 1～5 分评估：

| 维度 | 核心问题 |
|---|---|
| 任务完成度 | 是否真正完成了业务目标？ |
| 主体真实性 | 结构、比例、数量、身份是否准确？ |
| 视觉质量 | 构图、光影、色彩、材质是否可信？ |
| 编辑边界 | 未授权区域是否被污染或重绘？ |
| 融合质量 | 透视、尺度、遮挡、阴影、反射和边缘是否自然？ |
| 文字正确性 | 拼写、数字、Logo、标签是否准确？ |
| 品牌一致性 | 色板、字体、调性、版式是否统一？ |
| 平台适配 | 比例、留白、安全区和信息层级是否符合当前规范？ |
| 商业与法律风险 | 是否涉及侵权、虚假宣传或未授权肖像？ |
| 可复现性 | 是否保存输入、指令、参数、候选和修改记录？ |
