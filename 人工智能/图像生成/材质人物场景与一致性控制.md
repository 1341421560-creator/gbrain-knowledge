## 1. 材质描述框架

材质描述公式：

~~~text
材质类别 + 表面状态 + 粗糙度 + 反射/透光 + 纹理尺度和方向 + 厚度与边缘 + 与光线的互动 + 磨损状态
~~~

| 字段 | 要回答的问题 | 示例 |
|---|---|---|
| 基础材质 | 由什么构成？ | 玻璃、不锈钢、铝、棉、丝绸、皮革、木材、塑料 |
| 表面状态 | 表面怎样处理？ | 哑光、抛光、喷砂、磨砂、拉丝、上釉、湿润 |
| 粗糙度 | 高光锐利还是扩散？ | 低粗糙度镜面、高粗糙度漫反射 |
| 反射 | 反射强度和清晰度？ | 清晰环境反射、模糊反射、窄镜面高光 |
| 透光 | 是否透明、半透明或折射？ | 透明、乳白半透明、背光透亮 |
| 纹理 | 纹理的尺度、方向和密度？ | 细密横向拉丝、粗针织、细颗粒磨砂 |
| 厚度与边缘 | 薄片还是厚壁？ | 厚玻璃杯沿、倒角金属边、缝线毛边 |
| 光线互动 | 哪种光表现材质？ | 侧光显纹理、逆光显透光、条形高光显曲面 |
| 使用状态 | 全新、自然使用或磨损？ | 全新无划痕、轻微使用痕迹、自然折痕 |

不够有效：

~~~text
让它更高级、更有质感、更真实。
~~~

更有效：

~~~text
机身为深灰色喷砂阳极氧化铝，表面细腻哑光，沿纵向有极细拉丝纹理；左侧大面积柔光形成宽而弱的渐变高光，倒角边缘出现窄亮轮廓，暗部保留金属颗粒，不出现塑料般均匀亮斑。
~~~

<a id="glass-material"></a>
## 2. 玻璃、透明与半透明材质

常用描述词：

| 中文 | 英文 | 视觉含义 |
|---|---|---|
| 透明 | transparent | 能看见后方内容 |
| 半透明 | translucent | 透光但背景细节模糊 |
| 磨砂 | frosted | 表面散射，反射和透视变柔 |
| 折射 | refraction | 后方景物发生合理偏移或变形 |
| 内部反射 | internal reflection | 玻璃内部和边缘出现多次反射 |
| 边缘高光 | edge highlight | 依靠轮廓亮线显示形体 |
| 逆光 | backlit | 光从后方穿过透明物 |
| 次表面散射 | subsurface scattering | 光进入半透明材质后柔和扩散 |
| 焦散 | caustics | 透明物把光聚集成亮纹；仅在场景需要时使用 |
| 色散 | dispersion | 棱镜式彩色分离；不要无依据滥用 |

玻璃控制要点：

1. 说明透明、半透明还是磨砂，不能混用互相矛盾的词。
2. 描述玻璃壁厚、杯沿、底部和边缘，不然容易像薄塑料。
3. 使用逆光或侧逆光显示轮廓、折射和内部结构。
4. 说明背景通过玻璃后如何轻微变形或变模糊。
5. 透明物仍有高光、反射、阴影和接触关系，不是“完全看不见”。
6. 深色背景有助于显示透明轮廓，但必须保留真实环境反射。

透明玻璃模板：

~~~text
[物体] 由厚壁透明玻璃制成，杯沿和底部厚度清晰，具有真实折射、内部反射和窄边缘高光。主光从后方略偏左穿过玻璃，背景经过玻璃后产生轻微合理位移；底部形成淡而有颜色的透光接触阴影。保持物体轮廓、尺寸、文字和位置准确，不要画成白色实体、亚克力或镜面金属。
~~~

磨砂玻璃模板：

~~~text
表面为细腻均匀的烟灰色磨砂玻璃，半透明，后方轮廓可见但细节被柔和散射。边缘和厚处颜色更深，逆光处有柔和透亮感；表面反射宽而模糊，不出现清晰镜像。
~~~

半透明材质通用组合可参考“translucent + backlit + subsurface scattering”，但是否合适取决于材质；玻璃以折射和反射为主，皮肤、蜡、玉石等更适合强调次表面散射。

<a id="metal-material"></a>
## 3. 金属与反光材质

先判断金属表面处理：

- **镜面抛光：** 反射清晰、边界锐利，对环境极敏感。
- **亮面抛光：** 有强镜面高光，但反射不一定完全清晰。
- **拉丝：** 沿纹理方向出现拉长高光，具有各向异性反射。
- **喷砂/磨砂：** 高光宽而柔，表面细颗粒明显。
- **阳极氧化：** 颜色均匀、带金属底层反射，常见于铝合金。
- **镀铬：** 强烈镜面反射、亮暗反差大。
- **氧化或做旧：** 有颜色变化、斑驳和细微腐蚀，不能与全新商品混用。

金属描述词：

- specular highlights：镜面高光。
- anisotropic reflection：各向异性反射。
- brushed grain：拉丝纹理。
- polished metal：抛光金属。
- mirror-like reflection：镜面反射。
- satin metal finish：缎面金属处理。
- micro-scratches：细微划痕；只有真实需要时使用。
- beveled edge highlight：倒角边缘高光。

拉丝金属模板：

~~~text
外壳为银灰色拉丝铝，细密纹理沿垂直方向排列。左侧条形柔光在表面形成沿拉丝方向延展的各向异性高光，右侧暗部反射环境的深灰色，不出现塑料亮斑。倒角边缘有窄而连续的高光，结构和开孔完全准确。
~~~

镜面金属模板：

~~~text
表面为高抛光不锈钢，反射清晰但受控，能够映出两侧大面积柔光箱的长条高光和周围暗色环境。反射遵循曲面形状连续变化，不出现无来源白斑、重复反射或液体般扭曲。
~~~

“重新打光，更好展示商品”太宽泛。更可执行的写法：

~~~text
保持商品结构、颜色和表面处理不变，重新建立左前方大柔光为主光、右侧黑旗形成暗边、后方窄轮廓光勾勒外形的棚拍光。让金属曲面出现连续的长条高光，以高光宽度和弯曲显示体积；暗部仍保留接口和拉丝细节。
~~~

<a id="other-materials"></a>
## 4. 织物、皮革、塑料、木材与皮肤

**织物**

- 棉：哑光、柔软、细密织纹、自然褶皱。
- 亚麻：较粗纤维、轻微不规则、干爽、自然折痕。
- 丝绸/缎面：高光流动、明暗随褶皱变化，不等于镜面塑料。
- 羊毛针织：可见纱线、针法、毛绒感、厚度和弹性。
- 牛仔：斜纹结构、较硬挺、缝线和自然磨白。
- 天鹅绒：方向性绒毛，随视角产生深浅变化。

织物模板：

~~~text
服装为 [材质]，可见 [织纹/针法/纤维]，表面 [哑光/柔和光泽]。褶皱由人物姿势和受力自然形成，在肩部、肘部和腰部出现合理拉伸与堆叠。侧向柔光显示纹理，暗部仍保留纱线细节，不要变成光滑塑料。
~~~

**皮革**

- 区分光面皮、荔枝纹、麂皮、漆皮。
- 描述毛孔或压纹尺度、缝线、边油和折弯处高光。
- 漆皮反射锐利；麂皮反射柔和并有方向性绒毛。
- 不要同时使用“完全哑光”和“镜面高反射”等冲突词。

**塑料**

- 说明哑光、半光泽、透明或橡胶化涂层。
- 注塑件常有均匀表面、分模线或细微纹理，但不得凭空添加生产缺陷。
- 亮面塑料有镜面高光，反射强度通常低于镀铬金属。

**木材**

- 说明木种观感、纹理方向、开放或封闭毛孔、哑光油蜡或亮面漆。
- 木纹要沿物体结构连续，避免无规律旋涡和重复贴图。
- 边缘和端面纹理应与正面纹理不同。

**皮肤**

- 使用自然肤色变化、细微毛孔、柔和高光和次表面散射。
- 保留年龄相符的纹理，不把真实人物过度磨皮成蜡像。
- 避免将肤色、族裔或面部特征与性格、职业等刻板印象绑定。

<a id="spatial-relations"></a>
## 5. 多产品与空间关系

多对象场景必须写清每个对象的位置、数量、尺度、朝向和遮挡。

常用空间词：

| 关系 | 表达 |
|---|---|
| 左右 | to the left/right of, centered between |
| 前后 | in front of, behind, foreground, background |
| 上下 | above, below, on top of, underneath |
| 接触 | resting on, attached to, held by, leaning against |
| 包含 | inside, partially inside, surrounding |
| 遮挡 | partially occluding, fully visible, peeking from behind |
| 距离 | adjacent to, separated by, evenly spaced |
| 朝向 | facing left/right, angled toward, parallel to |
| 排列 | in a row, circular arrangement, staggered layout, grid |
| 层次 | foreground → subject → background |

对象清单法：

~~~text
对象 A：白色主商品，位于画面中央前景，朝向右前方，占画面高度 55%。
对象 B：透明玻璃杯，位于商品右后方，大小约为商品高度的 40%，被商品轻微遮挡。
对象 C：绿色植物，位于左后方背景，只作为模糊色块，不遮挡商品。
三者都落在同一桌面，遵循同一透视和左侧窗光。
~~~

数量要求要逐项验收。生成“20 套餐具”“8 个人”等高数量场景时，模型可能漏项或复制。可将对象按桌位、区域或行列分组，并在输出后人工计数；精确数量是硬要求时，优先后期排版或三维/图形工具。

<a id="scale-control"></a>
## 6. 尺寸、比例和尺度控制

比例控制公式：

~~~text
主体真实尺寸 + 参照物尺寸 + 相对关系 + 同一平面与相机距离 + 视角 + 禁止透视误导
~~~

示例：

~~~text
商品实际高度 12 厘米，旁边放置直径约 24 毫米的常见硬币作为尺寸参照。两者位于同一桌面、到相机距离接近，使用略高的三分之四视角。商品高度约为硬币直径的 5 倍，不要使用夸张广角或近大远小效果。
~~~

人物手持示例：

~~~text
成年人的单手自然握持商品，手掌长度按约 18 厘米的常见尺度表现；商品能被一只手舒适握住。保持手指数量、关节、抓握受力和商品真实尺寸关系，不能为了突出商品而把手缩小。
~~~

注意：

- 人体、硬币和手机型号的真实尺寸存在差异，知识库中的数值只能作为示例。
- 商业详情页的精确尺寸必须来自真实数据，并通过文字或图形标注确认。
- AI 视觉比例不能代替工程尺寸图。

<a id="camera-depth"></a>
## 7. 镜头、焦点与景深

镜头语言分四部分：

1. **机位：** 眼平、俯拍、顶视、低机位、三分之四角度。
2. **焦段感：** 广角强调空间、标准视角自然、中长焦压缩空间、微距强调细节。
3. **焦点：** 明确对焦对象和关键细节。
4. **景深：** 前景、主体、背景各自清晰程度。

常用表达：

- “sharp focus on the product logo and front edge”
- “subject sharp, background softly blurred”
- “deep focus, foreground and background both legible”
- “shallow depth of field with natural optical falloff”
- “macro detail of stitching, no loss of fabric texture”
- “rectilinear perspective, minimal edge distortion”

模板：

~~~text
采用中长焦商品摄影的压缩透视感，三分之四机位，焦点准确落在商品正面 Logo 和关键结构上。商品整体清晰，背景从商品后方开始逐渐柔和虚化；前景道具不遮挡卖点。不要把商品边缘、文字或接口一起虚化。
~~~

摄影参数是视觉提示而非可靠元数据。写“85mm 焦段感、f/2.8 式浅景深”可以表达效果，但不要声称一定来自某台相机。

<a id="complex-materials"></a>
## 8. 复杂材质混合与优先级

复杂场景按优先级分段，不假设所有模型理解自定义权重：

1. 主体身份与结构。
2. 商品关键材质和卖点。
3. 各部件的材质边界。
4. 空间关系与构图。
5. 光影和环境。
6. 风格与装饰。

部件级描述：

~~~text
金属边框：深灰色拉丝铝，纵向细纹，窄条高光。
正面面板：黑色玻璃，低反射，可见轻微环境亮部。
握带：粗织黑色尼龙，哑光，纤维和缝线清晰。
按键：半光泽塑料，略高于表面，边缘准确。
不同材质严格限制在各自部件，不渗色、不串纹理。
~~~

复杂材质结构化模板：

~~~json
{
  "priority": [
    "product_identity_and_geometry",
    "critical_materials",
    "spatial_relationships",
    "lighting",
    "style"
  ],
  "parts": {
    "frame": {
      "material": "brushed aluminum",
      "color": "dark gray",
      "texture_direction": "vertical",
      "reflection": "soft anisotropic highlight"
    },
    "front_panel": {
      "material": "black glass",
      "transparency": "opaque",
      "reflection": "low, controlled"
    },
    "strap": {
      "material": "woven nylon",
      "finish": "matte",
      "details": "visible fibers and stitching"
    }
  },
  "locked": [
    "shape",
    "proportions",
    "logo",
    "text",
    "part boundaries"
  ]
}
~~~

JSON 用于组织要求和团队复用，不代表所有图像模型有对应的内部数值参数。诸如 roughness、metallic、refraction_index 等字段，只有工具明确支持时才作为真实参数；否则应转写为自然语言视觉描述。

<a id="seasonal-lifestyle"></a>
## 9. 节日、季节与真实使用场景

不要只写“加入某节日元素”。应拆成：

~~~text
节日/季节 + 时间和天气 + 代表性色板 + 3～5 个受控元素 + 商品位置 + 光影 + 禁止项
~~~

节日场景模板：

~~~text
在保持商品完全不变的前提下，把环境调整为 [节日/季节] 场景。使用 [主色、辅色] 色板，在背景加入 [元素 1、元素 2、元素 3]，装饰只占次要位置，不遮挡商品、Logo 和卖点。照明为 [方向、软硬、色温]，商品接受同一环境光。不要添加未经授权的节日文字、品牌标志或价格信息。
~~~

真实使用场景要描述动作链：

~~~text
人物用右手握住商品的指定握持区，拇指自然放在按键旁，手指顺着外壳弧度包裹；商品正在 [真实功能状态]。手部受力、关节角度和遮挡自然，不能遮住 Logo 和核心卖点。保持商品结构和实际功能，不制造不存在的使用效果。
~~~

“正在工作”必须来自真实功能。不得把静态商品画成拥有未声明的发光、喷雾、医疗或性能效果。

<a id="multi-reference"></a>
## 10. 多参考图融合

三种通用方法：

**方法一：结构辅助**

- 原图提供商品真实外观。
- 线稿、轮廓图、深度图或姿态图只提供结构和空间。
- 指令声明辅助图不提供颜色、材质、文字和背景。
- 适合复杂轮廓、家具空间和明确遮挡关系。

~~~text
图 1 提供商品真实结构、颜色、材质和文字；图 2 只提供轮廓和边缘；图 3 只提供前中后景深度关系。以图 1 商品事实为最高优先级，沿用图 2 轮廓和图 3 空间层次，把商品自然放入场景。不要把辅助图的伪彩色、线条或标记保留在结果中。
~~~

**方法二：反推提示词 + 原图**

1. 先反推参考场景的构图、光影、材质和镜头。
2. 删除参考中的品牌、主体和不可复制内容。
3. 使用商品原图 + 清理后的场景提示词生成。
4. 锁定商品事实，避免风格覆盖产品结构。

**方法三：标记辅助**

1. 在原图副本上用明显颜色圈出要修改的位置。
2. 用文字描述具体动作、尺度和空间关系。
3. 明确“完成后删除标记颜色”。
4. 仍以未标记原图或单独商品图提供真实细节。

比例不协调修正：

~~~text
只调整新增人物的尺度和位置：人物当前过小，请依据房间高度、沙发和透视消失线重新计算，使其符合成年人真实比例。保持人物身份、姿势、商品、背景、光线和构图不变。
~~~

<a id="people-inpainting"></a>
## 11. 人物换装与局部重绘

换装需要同时锁定人物和服装事实：

~~~text
把图 2 的服装准确穿到图 1 的人物身上，只替换服装区域。保持图 1 的人物身份、面部、发型、肤色、表情、姿势、身体比例、手部、背景、镜头和光线不变。

服装的版型、领口、袖长、颜色、图案、材质、织纹、缝线、纽扣、口袋和 Logo 以图 2 为准。根据人物姿势形成自然褶皱、拉伸、压缩和遮挡；不要带入图 2 的模特、背景或拍摄光线。
~~~

换装边界检查：

- 领口与脖颈。
- 发丝与衣领。
- 袖口与手腕、手指。
- 腰线与身体比例。
- 透明纱、蕾丝和镂空。
- 图案在褶皱和遮挡处的连续性。
- Logo、文字、纽扣、拉链和口袋数量。
- 服装在坐姿、抬臂或转身时的受力。

局部重绘通用公式：

~~~text
使用提供的图片，仅将 [特定元素/区域] 更改为 [新元素/状态]。编辑范围严格限制在 [边界]。保持图片中其他所有内容完全不变，并让新区域继承原有风格、光线、透视、噪声和构图。
~~~

<a id="identity-control"></a>
## 12. 人物身份与面孔控制

人物身份描述应记录稳定、可观察、与任务相关的特征：

- 成年年龄段。
- 脸型、眉眼、鼻型、唇形和明显特征。
- 肤色范围和自然皮肤纹理。
- 发色、发型、发际线和长度。
- 身高体型和身体比例。
- 固定眼镜、耳饰、痣或其他关键配饰。
- 默认表情和气质。
- 禁止变化项。

角色锁定模板：

~~~text
同一成年人物，保持脸型、五官间距、眉形、眼睛颜色、鼻型、唇形、肤色、发际线、发色、发型、年龄感和固定配饰一致。保留自然皮肤纹理，不改变身份。只修改 [服装/姿势/场景]，不要改变面部、体型和身体比例。
~~~

换脸或肖像编辑只对获得授权的素材执行，并清楚标记合成用途。不要以种族刻板印象代替具体面部特征，也不要把群体身份与性格、审美或职业模板绑定。

面部编辑边界：

~~~text
只使用图 2 提供人物面部身份特征，并自然适配图 1 的头部朝向、表情、光线、肤色过渡和景深。保持图 1 的身体、姿势、服装、手部、背景和构图不变。发际线、耳朵、下颌、脖颈和遮挡边缘必须连续自然。
~~~

<a id="series-consistency"></a>
## 13. 系列一致性工作流

一致性来自稳定输入和可复现记录，而不是一句“保持一致”：

1. 选择一张结构和身份最准确的基准图。
2. 建立固定主体卡：结构、颜色、材质、文字、人物特征和禁改项。
3. 固定色板、镜头语言、光影方案和后期调性。
4. 每轮只改变姿势、服装、场景或构图中的一个主要变量。
5. 参考图编号和职责始终一致。
6. 工具支持种子、身份参考或角色控制时保存参数。
7. 每张图先单独验收，再做系列横向对比。
8. 发生漂移时回到基准图，不要继续在错误结果上累积修改。

主体卡示例：

~~~text
角色 ID：成人女性 A
固定：椭圆脸、深棕色杏仁眼、深棕色中分低发髻、自然橄榄色肤色、黑色方框眼镜、修长匀称体型。
固定视觉：眼平机位、自然生活方式摄影、中性日光、低饱和暖灰调。
允许变量：服装、动作、房间位置。
禁止变量：年龄、五官、发型、肤色、眼镜、身体比例。
~~~

商品系列也可使用同样结构，把角色特征替换为商品结构、颜色分区、材质、Logo、文字和关键尺寸。

<a id="failure-correction"></a>
## 14. 常见失败与修正

| 问题 | 原因 | 修正 |
|---|---|---|
| 玻璃像白色塑料 | 未描述折射和边缘 | 补充透明度、壁厚、边缘高光、背景折射和透光阴影。 |
| 金属像塑料 | 缺少环境反射 | 写明表面处理、高光形状、反射来源和纹理方向。 |
| 织物变光滑 | 过度强调“光泽” | 指定织法、纤维、哑光程度、褶皱和侧光。 |
| 材质串色 | 没有部件边界 | 按部件分别描述，并写“不得跨越原有边界”。 |
| 数量错误 | 对象太多且未分组 | 使用对象清单和分区，输出后人工计数。 |
| 尺寸误导 | 参照物和透视错误 | 使用真实数据、同一平面和相近相机距离。 |
| 商品被背景遮挡 | 空间关系不清 | 明确前后、遮挡比例和不可遮挡卖点。 |
| 景深虚化了 Logo | 焦点范围没写 | 明确 Logo 和关键结构在焦内。 |
| 换装后变脸 | 编辑区太大 | 仅编辑服装，逐项锁定人物身份。 |
| 花纹在褶皱处断裂 | 缺少表面映射描述 | 要求图案随布料曲面和褶皱连续变形。 |
| 多轮人物漂移 | 没有固定基准 | 回到基准图和主体卡，每轮只改一个变量。 |
| 新增动作不符合功能 | 功能被想象 | 只描述经确认的真实动作和状态。 |

<a id="templates"></a>
## 15. 可复制提示词模板

**材质商品图**

~~~text
保持 [商品] 的结构、比例、文字、Logo 和颜色分区准确。
部件 A：[材质 + 表面处理 + 纹理方向 + 反射/透光]。
部件 B：[材质 + 表面处理 + 纹理方向 + 反射/透光]。
使用 [光源方向和性质] 显示各材质差异，各部件边界清晰，不发生纹理渗色、反射串用或材质混淆。
构图：[机位、占比、背景]。输出：[比例和分辨率]。
~~~

**多产品组合**

~~~text
创建 [场景]，包含准确的 [数量] 个对象。
对象 A：[外观]，位于 [位置]，朝向 [方向]，占比 [关系]。
对象 B：[外观]，位于 [位置]，与 A 的关系为 [前后左右、距离、遮挡]。
对象 C：[外观]，位于 [位置]。
所有对象共享同一地面、透视、主光和阴影方向，不重复、不融合、不遗漏。
~~~

**人物生活方式图**

~~~text
同一成年人物，锁定 [面部、发型、肤色、体型和固定配饰]。人物在 [真实环境] 中执行 [具体动作链]，与 [商品] 发生 [握持、穿戴、使用] 关系。手部受力、关节、遮挡和商品尺度自然。光线为 [描述]，构图为 [描述]。只改变 [变量]，其他身份和商品事实不变。
~~~

<a id="checklist"></a>
## 16. 验收清单

- [ ] 每种材质都写明表面状态、纹理、反射或透光。
- [ ] 玻璃有真实边缘、折射、内部反射和透光阴影。
- [ ] 金属高光和反射有明确光源，拉丝方向连续。
- [ ] 织物的纤维、针法、褶皱和光泽符合材质。
- [ ] 不同部件没有材质渗色和纹理重叠。
- [ ] 多对象数量、位置、朝向、尺度和遮挡准确。
- [ ] 尺寸关系来自真实数据，透视不误导。
- [ ] 焦点覆盖 Logo、文字和关键卖点。
- [ ] 换装只改变服装，人物身份和身体比例稳定。
- [ ] 手指、发丝、透明边缘、图案和缝线自然连续。
- [ ] 系列图使用同一基准图、主体卡和视觉规范。
- [ ] 真实人物、商品功能、品牌和素材均已授权和核验。
