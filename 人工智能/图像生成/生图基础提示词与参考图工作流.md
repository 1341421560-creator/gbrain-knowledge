## 1. 任务类型与输入准备

开始前先判断任务，不同任务的写法不同：

| 任务 | 输入 | 核心动作 | 必须锁定 |
|---|---|---|---|
| 文生图 | 文字 | 从零创建画面 | 主体事实、数量、构图和输出规格 |
| 图生图 | 原图或参考图 + 文字 | 保留部分信息后重绘 | 参考图职责和变化范围 |
| 局部编辑 | 原图 + 区域描述或蒙版 | 只改指定元素 | 未编辑区域 |
| 元素替换 | 原图，可加目标元素参考图 | 用新元素替换旧元素 | 位置、尺度、透视、遮挡、光影 |
| 添加元素 | 原图，可加元素参考图 | 在指定位置放入新元素 | 原场景和已有主体 |
| 删除元素 | 原图 | 删除后重构被遮挡背景 | 周围纹理、边缘和光照连续性 |
| 换背景 | 主体图 + 背景图或文字 | 保留主体并重建环境 | 主体结构、Logo、颜色和材质 |
| 换色或换材质 | 原图 | 改变表面属性 | 结构、纹理、反射逻辑和原有明暗 |
| 扩图 | 原图 + 新画布比例 | 延展画面 | 透视、纹理、光源和主体位置 |
| 批量变体 | 基准图 + 变量表 | 只改变指定变量 | 所有不变量和命名规则 |

输入图准备：

- 主体清晰、无遮挡，重要结构、文字和 Logo 可辨认。
- 复杂商品提供正面、侧面、背面和细节图，不要求 AI 猜测看不见的结构。
- 细节卖点应使用近距离原图；从全景图裁切出来的局部通常缺少真实细节。
- 减少强滤镜、过曝、压缩噪声和与商品无关的干扰物。
- 多张图要编号，并在指令中声明每张图的唯一职责。
- 涉及真实商品时，以实拍事实为最高优先级，审美参考不得覆盖商品事实。

开始写指令前回答五个问题：

1. 要生成、替换、添加、删除、扩展，还是只调整颜色或光线？
2. 哪个区域或元素允许变化？
3. 哪些内容必须完全保持不变？
4. 新内容应怎样继承原图的位置、透视、遮挡、光影和风格？
5. 输出用于哪里，比例、分辨率、留白和验收要求是什么？

<a id="prompt-architecture"></a>
## 2. 提示词的信息架构与写法

推荐顺序：

~~~text
任务动作 → 目标定位 → 新内容描述 → 空间与几何 → 光影与材质 → 风格与镜头 → 锁定区 → 输出规格 → 验收要求
~~~

| 层级 | 要回答的问题 | 示例 |
|---|---|---|
| 任务动作 | 要做什么？ | 生成、替换、添加、删除、修复、扩展 |
| 目标定位 | 改哪一个？ | 前景左侧、人物右手中、桌面中央、带银色边框的黑色设备 |
| 新内容 | 改成什么？ | 图 2 中的白色产品、深红色羊毛外套、磨砂玻璃花瓶 |
| 空间几何 | 放在哪里、大小和角度如何？ | 保持中心点、占画面比例、旋转角度、透视和遮挡关系 |
| 光影 | 如何接受原场景照明？ | 继承左上方柔光、保留接触阴影、匹配环境反射 |
| 材质 | 表面怎样表现？ | 哑光、拉丝、半透明、细密织纹、窄高光 |
| 风格镜头 | 视觉语言是什么？ | 写实商品摄影、俯拍、低机位、浅景深 |
| 锁定区 | 什么不能改变？ | 人物身份、商品结构、文字、Logo、背景、构图 |
| 输出 | 如何交付？ | 1:1、4:5、透明背景、纯白背景、保留安全区 |
| 验收 | 怎样算完成？ | 无边缘光晕、无多余部件、文字准确、阴影方向一致 |

写法原则：

- **先动词，后描述。** 开头直接写“只替换”“仅删除”“在指定位置添加”，避免让模型先猜任务。
- **属性优先定位。** 使用“位置 + 颜色 + 类型 + 独特特征”定位目标，不用“那个”“旁边的东西”。
- **写可观察事实。** “拉丝银色金属，细长纵向纹理，边缘有窄高光”比“高级金属感”更可执行。
- **区分事实与审美。** 商品结构和文字是硬约束；“高级、温暖、活泼”只是软偏好。
- **正向描述为主。** 先说明正确画面应是什么，再补充禁止项。
- **每轮只改变一个主要变量。** 复杂修改拆成多轮，可显著减少全图漂移。
- **不要迷信长度。** 细节多但相互冲突，会比短而明确的指令更不稳定。

让语言模型帮助编写生图提示词时，可直接使用：

~~~text
你是一名 AI 图像提示词架构师。请把我的需求整理成可直接用于通用 AI 生图或图像编辑的指令。
先区分：必须准确的事实、允许变化的内容、禁止变化的内容。
再按以下顺序输出：
1. 任务动作
2. 主体与目标区域
3. 场景和空间关系
4. 构图与镜头
5. 光影
6. 材质与细节
7. 输出规格
8. 不可变约束
9. 失败时的修正短句
不要添加我没有提供的商品功能、认证、尺寸、文字或品牌信息。
~~~

<a id="descriptor-library"></a>
## 3. 常用描述词库

描述词不是越多越好。每类选择与任务真正相关的 1～4 个，并写清它们作用在哪个对象上。

| 类别 | 中文描述词 | 常见英文表达 | 用途 |
|---|---|---|---|
| 位置 | 前景、背景、中央偏左、右上角、人物身后、桌面中央 | foreground, background, center-left, behind the subject | 精确定位目标 |
| 几何 | 保持中心点、相同占比、相同角度、轮廓吻合、透视一致 | same center, scale, angle, silhouette, perspective | 防止替换后大小和角度漂移 |
| 遮挡 | 位于前方、被局部遮挡、穿过、贴合、置于其后 | in front of, partially occluded, behind, attached to | 建立前后关系 |
| 光线方向 | 左上方主光、正面柔光、逆光、侧逆光、顶光 | key light from upper left, front soft light, backlit, rim light | 统一照明 |
| 光线性质 | 柔和漫射光、硬光、低对比、高对比、暖色、冷色 | soft diffused light, hard light, low contrast, warm/cool light | 控制明暗与氛围 |
| 阴影 | 接触阴影、投射阴影、边缘柔化、方向一致 | contact shadow, cast shadow, soft shadow edge | 让新增元素落地 |
| 金属 | 拉丝、抛光、镜面、阳极氧化、各向异性反射、窄高光 | brushed, polished, mirror-like, anodized, anisotropic reflection | 描述金属表面 |
| 玻璃 | 透明、半透明、磨砂、折射、内部反射、边缘高光 | transparent, translucent, frosted, refraction, internal reflection | 描述玻璃与透光 |
| 织物 | 细密织纹、粗针织、丝滑、起绒、自然褶皱 | fine weave, chunky knit, silky, brushed, natural folds | 描述服装和软材质 |
| 塑料 | 哑光、半光泽、注塑纹理、均匀表面 | matte, semi-gloss, injection-molded texture | 避免塑料被画成金属 |
| 皮肤 | 自然纹理、细微毛孔、柔和高光、真实肤色变化 | natural skin texture, subtle pores, soft highlights | 减少蜡像感 |
| 边缘 | 轮廓干净、抗锯齿、无白边、无灰边、无光晕 | clean silhouette, anti-aliased, no halo, no fringe | 抠图和合成验收 |
| 构图 | 居中、三分法、对称、负空间、主体占比 | centered, rule of thirds, symmetrical, negative space | 控制版式 |
| 机位 | 眼平、俯拍、顶视、低机位、斜俯视 | eye-level, overhead, top-down, low-angle, three-quarter view | 控制观看角度 |
| 景别 | 特写、近景、中景、全身、环境远景 | close-up, medium shot, full-body, wide environmental shot | 控制裁切范围 |
| 焦段感 | 广角透视、标准视角、中长焦压缩、微距 | wide-angle perspective, normal perspective, telephoto compression, macro | 描述空间感 |
| 景深 | 全景清晰、主体清晰背景轻虚化、浅景深 | deep focus, subject sharp with soft background, shallow depth of field | 控制焦点 |
| 写实风格 | 商品摄影、生活方式摄影、纪实、编辑大片 | product photography, lifestyle photography, documentary, editorial | 定义视觉类型 |
| 插画风格 | 扁平插画、线稿、水彩、黏土、纸雕、3D 卡通 | flat illustration, line art, watercolor, clay, paper-cut, 3D cartoon | 定义媒介 |
| 质量约束 | 结构准确、数量正确、纹理连续、无伪影 | accurate structure, correct count, continuous texture, no artifacts | 指定验收目标 |

关于摄影参数：

- “35mm、85mm、f/2.8”等词通常是视觉语言，用于表达透视和景深感，不代表模型真的模拟了对应器材。
- 只有在参数能解释视觉效果时才写；不要用大量器材名替代主体、构图和光影描述。
- 无法从参考图确定的参数应写成“近似焦段感”或“推测”，不要伪装成事实。

<a id="reference-roles"></a>
## 4. 参考图的职责分配

多图输入时，每张图只承担明确角色：

- **主体参考：** 形状、身份、颜色、结构、Logo 和关键细节。
- **目标元素参考：** 要替换进去的具体商品、服装、人物或道具。
- **材质参考：** 表面纹理、反射、透光和粗糙度。
- **构图参考：** 主体位置、镜头距离、画布比例和留白。
- **光影参考：** 主光方向、软硬、色温和阴影。
- **风格参考：** 色彩、媒介和视觉调性。
- **背景参考：** 空间、透视、环境元素和景深。

标准写法：

~~~text
图 1 是待编辑原图，提供场景、构图、人物和光影。
图 2 只提供要替换进去的商品外形、颜色、材质、Logo 和细节。
优先级：商品事实以图 2 为准；位置、尺度、透视、遮挡、背景和照明以图 1 为准。
不要把图 2 的背景、拍摄角度或其他道具带入结果。
~~~

参考冲突时必须声明优先级。例如：

~~~text
主体结构和文字以图 1 为最高优先级；构图只参考图 2；光影只参考图 3。发生冲突时，不得为了模仿图 2 或图 3 而改变图 1 的商品事实。
~~~

## 5. 替换任意图像中元素：完整用法

元素替换不是一句“把 A 换成 B”，而是六个连续动作：

1. **语义选择：** 用属性准确定位原图中的唯一目标。
2. **目标注入：** 描述新元素，或指定哪张参考图提供新元素事实。
3. **几何继承：** 保持原目标的位置、占比、角度、透视和遮挡。
4. **环境锚定：** 让新元素继承原场景的光线、阴影、反射、色温和景深。
5. **锁定未编辑区：** 列出人物、背景、构图、文字等不可变化项。
6. **边缘验收：** 检查轮廓、接触处、遮挡处和复杂细节是否自然。

**1）语义选择语法**

不够明确：

~~~text
把那辆车换掉。
~~~

更可靠：

~~~text
识别并选中画面前景中央、车身为红色、带圆形前灯和银色保险杠的复古轿车。只修改这辆车。
~~~

推荐定位公式：

~~~text
识别 [空间位置] 的 [颜色/材质] [对象类型]，其独特特征是 [轮廓、配件、文字或与周围物体的关系]。只编辑该对象及其必要的边缘过渡区域。
~~~

目标有多个相似对象时，加上排除定位：

~~~text
选择人物右手拿着的白色杯子，不要选择桌面左侧的另一个杯子。
~~~

**2）参考图注入**

~~~text
把图 2 中的商品替换到图 1 的目标位置。商品的结构、比例、颜色分区、材质、Logo 和文字以图 2 为准；位置、尺度、角度、透视、遮挡和光影以图 1 中原目标为准。
~~~

如果没有参考图，必须把新元素描述完整：

~~~text
替换为一只低矮的圆柱形磨砂玻璃花瓶，烟灰色半透明材质，瓶口略窄，表面没有文字和装饰，边缘有柔和透光高光。
~~~

**3）环境锚定与不可变约束**

~~~text
新元素必须自然继承原场景左上方柔和主光、右侧较弱补光、桌面的接触阴影、周围环境色反射和原有景深。保持原图人物、表情、姿势、手部、背景、构图、相机视角、画布比例、颜色分级和所有未授权细节不变。
~~~

**4）完整通用指令**

~~~text
使用图 1 作为待编辑原图。识别 [位置 + 属性 + 独特特征] 的 [旧元素]，只将它替换为 [新元素详细描述 / 图 2 中的元素]。

新元素必须继承旧元素在图 1 中的中心位置、画面占比、朝向、旋转角度、透视、遮挡关系和接触位置。根据图 1 的主光方向、光线软硬、色温、阴影、环境反射和景深重新渲染新元素，使其自然属于原场景。

如果使用图 2：只提取图 2 中新元素的结构、颜色、材质、Logo、文字和关键细节；不要带入图 2 的背景、构图、光影或无关物体。

除目标元素及必要的边缘融合区域外，保持图 1 的人物身份、面部、姿势、手部、已有商品、文字、Logo、背景、构图、镜头、光线、颜色和画布完全不变。不得新增、删除、复制或移动其他元素。

验收：目标选择正确；新元素没有变形或多余部件；比例与透视合理；遮挡、边缘、接触阴影和反射自然；未编辑区域与原图一致。
~~~

**5）商品替换示例**

~~~text
使用图 1 作为原场景。识别桌面中央、位于人物双手之间的黑色空气净化器，只把它替换为图 2 中的白色空气净化器。

白色商品的机身结构、顶部出风口、按键、颜色分区、Logo 和表面材质以图 2 为准。保持原黑色商品在图 1 中的中心点、宽高占比、三分之四朝向、桌面接触位置和人物手部遮挡关系。继承图 1 左前方柔和日光、机身右侧弱阴影、桌面接触阴影和室内暖色环境反射。

保持人物、手指、表情、服装、桌面、背景、构图、镜头和色调不变。不要带入图 2 的背景或包装，不要改写或虚构商品文字。
~~~

**6）标记辅助和蒙版**

模型或工具支持蒙版时：

- 蒙版只覆盖目标和必要的接触边缘，不要大面积覆盖背景。
- 毛发、手指、透明物、反光物和相互遮挡的边缘可分开处理。
- 蒙版边缘留少量融合缓冲，避免硬切、白边或旧元素残留。
- 如果目标难以用文字定位，可在原图副本上用明显颜色圈选；指令最后写明“完成编辑后移除标记颜色，不在结果中保留标记”。
- 标记图只用于定位，商品事实仍应来自未涂画的原图或单独参考图。

标记辅助示例：

~~~text
在红色圈选的位置添加一只趴卧的金毛犬，身体朝右，大小与旁边沙发比例协调，接受窗户方向的自然光并在地面形成柔和接触阴影。保持其他内容不变。完成后删除所有红色圈线和标记，不得在结果中保留红色痕迹。
~~~

<a id="common-edit-operations"></a>
## 6. 添加、删除、换色、换材质与换背景

**添加元素**

~~~text
在 [精确位置] 添加 [元素详细描述]。元素与 [参照物] 的大小比例为 [关系]，朝向 [方向]，位于 [前后遮挡关系]。匹配原图的透视、主光、阴影、环境反射和景深。不得移动或重绘原有元素。
~~~

**删除元素并重构背景**

~~~text
只移除 [位置 + 属性] 的 [目标元素]。根据其周围可见的 [墙面/地面/织物/头发/纹理] 连续重构被遮挡区域，保持纹理方向、透视、噪声、光照和颜色过渡自然。不要删除相邻元素，不要把该区域模糊化。
~~~

仅对自己拥有或获授权的素材执行覆盖物、标记或水印清理。复杂区域不要只写“移除”，还要描述应恢复的底层内容：

~~~text
移除夹克胸前的临时标记，并重构连续的黑色皮革纹理、缝线和拉链边缘。恢复区域的高光方向和颗粒应与周围皮革一致，不留下模糊、色块或重复纹理。
~~~

**换色**

~~~text
只把 [目标部件] 从 [原色] 改为 [目标色/色值]。保留原材质、纹理、粗糙度、高光、阴影、反射、缝线、Logo、文字和颜色分区；只改变基础色。其他区域完全不变。
~~~

**换材质**

~~~text
只把 [目标表面] 改为 [目标材质]。保持物体轮廓、尺寸、厚度、结构、颜色分区和所有文字不变。新材质表现为 [粗糙度、反射、纹理、透光特征]，并继承原场景光源和阴影。
~~~

示例：

~~~text
只把桌面中央花瓶的表面从亮面陶瓷改为烟灰色磨砂玻璃。保持花瓶轮廓、尺寸、瓶口厚度、位置和相机角度不变。玻璃半透明、表面细腻磨砂、边缘有柔和透光和轻微内部反射；不要改变花朵、桌面和背景。
~~~

**换背景**

~~~text
保留前景主体的结构、比例、颜色、材质、Logo、文字和边缘完全准确，只把背景替换为 [新环境]。按照新环境的光源方向和色温，对主体增加必要的环境反射与接触阴影，但不得重绘主体设计。
~~~

**人物换装**

~~~text
把图 2 的服装准确穿到图 1 的人物身上，只替换服装区域。人物身份、面部、发型、姿势、身体比例、手部、背景、镜头和光线保持不变。服装的版型、颜色、图案、材质、缝线和 Logo 以图 2 为准，并根据人物姿势形成自然褶皱、拉伸和遮挡。不要带入图 2 的模特或背景。
~~~

<a id="white-background-product"></a>
## 7. 商品白底图与干净抠图

平台规则会变化，实际发布前应另行核对当前平台要求。通用白底图指令：

~~~text
把提供的商品照片编辑为干净的白底商品图。只保留真实商品，移除手、人物、道具、包装、临时贴纸和环境元素。

背景为整个画布均匀的纯白色 RGB 255,255,255，不要渐变、纹理、暗角或地平线。根据实际用途选择是否保留自然接触阴影；如果要求无阴影，则同时移除投影、接触阴影和反射。

准确保留商品的设计、形状、比例、颜色、材质、表面纹理、Logo、文字和图案，不添加配件或不存在的细节。

商品居中，约占画面 [占比]% ，四周留白均匀，任何部位都不裁切。轮廓清晰、抗锯齿，无白边、灰边、光晕和锯齿，重点检查尖角、细杆、透明边缘、毛发和孔洞。商品受均匀柔和棚拍光照，背景仍保持纯白。

输出比例：[比例]；分辨率：[分辨率]。
~~~

常见补充短句：

- “不要把白色商品边缘溶进背景，保留完整轮廓和轻微边缘明暗。”
- “透明部件保持真实透明度和折射，不要填成纯白。”
- “商品文字逐字保持，不要重写、翻译或美化。”
- “所有开孔、按键、接口和数量必须与原图一致。”
- “如果原图信息不足，不要虚构背面结构或隐藏细节。”

## 8. 从参考图反推提示词

反推不是猜原作者写过的句子，而是提取可复现的视觉信息。建议按以下顺序分析：

1. 主体：类型、数量、姿态、身份、结构和材质。
2. 服装或产品细节：版型、配件、纹理、文字和颜色分区。
3. 环境：地点、时间、天气、道具和背景层次。
4. 构图：景别、机位、主体占比、视线、对称、留白。
5. 空间：前景、中景、背景、遮挡、透视和尺度。
6. 光影：主光方向、软硬、色温、阴影、高光和反射。
7. 色彩：主色、辅色、明度、饱和度、对比和调色倾向。
8. 镜头：焦段感、景深、运动感和画面畸变。
9. 风格：写实程度、媒介、颗粒、后期和情绪。
10. 可变字段：哪些部分可替换为其他商品、人物、服装或文字。

可直接复制的反推指令：

~~~text
请以视觉分析师和 AI 图像提示词架构师的身份，对上传图片进行深度逆向分析。目标不是猜测原作者的原始提示词，而是提取可复现的视觉事实。

请按“微观到宏观”分析：
1. 主体、数量、姿态、结构和身份特征
2. 服装或商品的版型、颜色、材质、纹理、文字和配件
3. 前景、中景、背景及对象之间的位置、尺度和遮挡
4. 构图、景别、机位、主体占比、视线和留白
5. 主光、补光、轮廓光、光线软硬、色温、阴影和反射
6. 主色、辅色、明度、饱和度、对比和后期调性
7. 焦段感、景深和透视；无法确定的真实器材参数请标记为“推测”
8. 写实程度、媒介、颗粒和整体视觉风格
9. 可能需要锁定的事实与可以替换的变量

输出四部分：
A. 一段可直接使用的完整自然语言提示词
B. 分字段的结构化提示词
C. 20～40 个按类别分组的关键描述词
D. 若用于局部编辑，给出“编辑区 + 锁定区 + 融合要求”指令
~~~

<a id="multi-turn-editing"></a>
## 9. 多轮编辑与复杂任务拆分

多轮编辑适合一次修改一个主要变量。例如：

~~~text
第 1 轮：只把蓝色汽车改为敞篷结构，保持颜色、位置、背景、光线和镜头不变。
第 2 轮：只把车身颜色从蓝色改为黄色，保持敞篷结构和其他内容不变。
第 3 轮：只在车尾增加一个与车身比例协调的尾翼，匹配原有材质、反射和光影。
~~~

复杂场景建议拆分：

1. 先确定背景、画布、透视和光源。
2. 再放入主商品，锁定结构和占比。
3. 再添加人物、手部或辅助道具。
4. 最后修正阴影、反射、边缘和文字。
5. 每一轮都重新声明关键锁定项，避免上下文逐轮漂移。

后续修正指令要指出具体偏差：

不够明确：

~~~text
再自然一点。
~~~

更可靠：

~~~text
只修正商品底部与桌面的接触关系：把接触阴影缩短并加深中心区域，向外逐渐变软；保持商品、人物、背景、构图和整体亮度不变。
~~~

<a id="iteration-debugging"></a>
## 10. 失败诊断与修正指令

| 问题 | 常见原因 | 可直接使用的修正指令 |
|---|---|---|
| 选错目标 | 定位词太少 | “只选择前景左侧带银色边框的黑色设备，不要修改右后方同类设备。” |
| 替换后大小不对 | 未继承原目标几何 | “让新元素与旧元素使用相同中心点、宽高占比、朝向和透视，不改变周围布局。” |
| 新元素像贴上去 | 缺少环境锚定 | “匹配主光方向、色温、接触阴影、环境反射、景深和噪声颗粒。” |
| 商品变形 | 场景要求压过商品事实 | “商品结构、比例、开孔、按键、Logo 和文字优先级最高，不得为适应场景而重绘。” |
| 参考图不起作用 | 未分配参考职责 | “图 2 只提供商品事实；图 1 提供位置、构图、光影和背景。” |
| 带入参考图背景 | 未限制提取范围 | “不要带入图 2 的背景、道具、人物、构图或拍摄光线。” |
| 未编辑区域变化 | 锁定项过于笼统 | “除目标及边缘融合区外，逐项保持人物、手部、服装、背景、文字、构图和画布不变。” |
| 删除后出现模糊块 | 未描述底层内容 | “重构连续墙面纹理和光照梯度，不要用模糊或纯色色块填充。” |
| 换色后材质丢失 | 只写了目标色 | “只改基础色，继承原纹理、粗糙度、高光、阴影、反射和缝线。” |
| 换装后人物变脸 | 编辑范围过大 | “仅编辑服装区域，锁定面部、发型、肤色、手部、姿势和身体比例。” |
| 手指或头发边缘坏 | 复杂边缘一次重绘 | “单独修复手指/发丝与新元素交界，保持数量、轮廓和遮挡关系。” |
| 文字或 Logo 错误 | 模型重绘文字 | “逐字保留原文字与 Logo；如无法准确保留，留空供后期排版，不得编造。” |
| 画面很美但不能用 | 缺少业务规格 | “保持现有内容，调整为 [比例]，主体占比 [范围]，为文案保留 [位置] 安全区。” |
| 系列图不一致 | 每轮重写主体 | “继续使用同一基准图和固定主体描述，只改变 [单一变量]。” |
| 指令互相冲突 | 同时要求保持和改变同一项 | 删除冲突句，把要求分成“事实、变量、禁改项”三栏后重写。 |

推荐迭代记录：

~~~text
本轮唯一变量：
上轮问题：
本轮修正：
必须保持：
输出编号：
验收结果：
下一轮是否继续：
~~~

<a id="model-variance"></a>
## 11. 模型差异与复现记录

不同 AI 对自然语言、负向提示词、种子、蒙版、参考权重、结构控制、多图输入和结构化 JSON 的支持不同：

- 先用清晰自然语言表达完整任务。
- 只有工具明确支持时，才使用专属参数。
- 负向提示词只是补充，不能替代正向的结构与锁定描述。
- 支持蒙版时用蒙版控制编辑边界；不支持时用语义定位和分轮编辑。
- 支持参考权重时，也要声明每张参考图的职责，不能只依赖数值。
- 生成模型不适合承担最终的精确排版、法务校对和商品事实审核。

每次可复现实验至少保存：

- 任务名称、日期、用途和负责人。
- 模型、版本和调用入口。
- 完整提示词、后续修正指令和负向提示词。
- 所有参考图、编号及其角色。
- 画布比例、分辨率、种子、编辑强度、参考权重；不支持时写“无”。
- 蒙版或标记图。
- 生成批次、候选编号、选片理由和淘汰原因。
- 后期修改记录、最终文件和验收结果。

## 12. 可复制的通用模板

**文生图**

~~~text
为 [用途] 生成 [主体]。主体事实：[结构、数量、颜色、材质、身份]。
场景：[环境、时间、天气、背景]。
空间与构图：[前中后景、景别、机位、主体占比、留白]。
光影：[主光方向、软硬、强度、色温、阴影和反射]。
风格与镜头：[写实/插画、焦段感、景深、调色]。
输出：[比例、分辨率、背景和安全区]。
约束：[不得改变、不得新增、不得虚构的内容]。
~~~

**图生图**

~~~text
图 1 用于主体结构，图 2 用于构图，图 3 用于光影。
优先保持图 1 的主体事实，把主体放入 [新场景]，沿用图 2 的空间关系和图 3 的照明逻辑。
不得改变 [结构、比例、Logo、文字、身份]，不得带入各参考图中的无关元素。
~~~

**局部编辑**

~~~text
只修改 [精确位置和目标元素] 为 [目标状态]。
编辑区：[允许改变的属性和边缘范围]。
锁定区：[主体身份、结构、比例、Logo、文字、材质、光线、构图、背景中不得改变的项]。
融合要求：[透视、尺度、遮挡、光线、阴影、反射、景深和边缘]。
验收：[结构、数量、文字、边缘和未编辑区一致性]。
~~~

**元素替换极简版**

~~~text
使用原图，只将 [位置 + 属性] 的 [旧元素] 替换为 [新元素/参考图中的元素]。保持原位置、大小、角度、透视、遮挡和接触关系，匹配原图光线、阴影、反射与景深。除目标和必要的边缘融合区外，其他所有内容完全不变。
~~~

**提示词精简指令**

~~~text
请检查下面的生图提示词，删除重复、冲突和不可验证的词语；保留商品事实、任务动作、空间关系、光影、材质、输出规格和不可变约束。按执行优先级重新排序，并指出仍缺少的信息。
~~~

## 13. 验收清单

- [ ] 任务动作写在开头，目标区域能够被唯一定位。
- [ ] 必须正确、允许变化和禁止变化三类信息已分开。
- [ ] 每张参考图的角色和优先级明确。
- [ ] 替换任务写明位置、尺度、角度、透视和遮挡继承。
- [ ] 新增或替换元素与原场景光线、阴影、反射和景深一致。
- [ ] 未编辑区域没有移动、变形、变色或被重新生成。
- [ ] 商品结构、数量、颜色分区、文字、Logo 和材质准确。
- [ ] 人物身份、面部、手指、发丝、姿势和身体比例准确。
- [ ] 边缘无白边、灰边、光晕、锯齿、残影或重复纹理。
- [ ] 输出比例、分辨率、留白和安全区符合实际用途。
- [ ] 已保存模型、提示词、参考图、参数、候选和修改记录。
- [ ] 已由人工检查商品事实、文字、授权、平台规则和商业风险。
