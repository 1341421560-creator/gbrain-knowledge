## 1. 光影系统与描述词

完整光影描述至少包含五项：

~~~text
光源方向 + 光线软硬 + 强度与对比 + 色温与颜色 + 阴影和反射
~~~

更完整时再加入主光、补光、轮廓光、背景光、光源面积、距离和环境反射。

| 维度 | 中文描述词 | 常见英文表达 |
|---|---|---|
| 方向 | 正面光、左侧光、右侧光、45 度侧光、顶光、逆光、底光 | front light, side light, 45-degree light, overhead light, backlight, underlight |
| 主次 | 主光、补光、轮廓光、背景光、反射补光 | key light, fill light, rim light, background light, bounce light |
| 软硬 | 硬光、柔光、漫射光、大面积柔光箱、聚光 | hard light, soft light, diffused light, large softbox, spotlight |
| 强度 | 明亮均匀、中等曝光、低照度、强烈照明、局部聚光 | bright and even, balanced exposure, dim, intense, focused beam |
| 色温 | 暖色、冷色、中性日光、暖冷混合、彩色氛围光 | warm, cool, neutral daylight, mixed temperature, colored ambient light |
| 对比 | 高调、低调、高对比、低对比、柔和渐变 | high-key, low-key, high contrast, low contrast, soft gradation |
| 特殊效果 | 体积光、窗光、百叶窗影、霓虹光、边缘光 | volumetric light, window light, venetian-blind shadows, neon glow, edge light |
| 阴影 | 接触阴影、投射阴影、软边、硬边、长阴影、短阴影 | contact shadow, cast shadow, soft-edged, hard-edged, long/short shadow |
| 反射 | 环境反射、镜面高光、漫反射、轮廓高光 | environmental reflection, specular highlight, diffuse reflection, rim highlight |

通用光影写法：

~~~text
主光从画面左上方约 45 度照射，为大面积柔和漫射光；右前方有较弱补光，降低暗部反差；产品后方有窄轮廓光，使边缘与背景分离。整体中性偏暖，阴影方向向右后方，接触处较深，向外逐渐变软变淡。
~~~

不要只写“高级光影”或“电影感”。必须说明光从哪里来、照到哪个表面、阴影落向哪里，以及产品材质如何响应。

## 2. 光位类型与适用场景

| 光位 | 视觉效果 | 常见用途 | 指令要点 |
|---|---|---|---|
| 平面光 | 阴影少、信息清楚 | 食品、化妆品、详情展示 | 正面大柔光、低对比、均匀曝光 |
| 45 度主光 | 形体立体、通用稳定 | 大多数商品 | 左前或右前 45 度，配弱补光 |
| 轮廓光 | 边缘清晰、与背景分离 | 耳机、手机、深色商品 | 产品后方窄条光，避免溢出轮廓 |
| 逆光 | 透明和液体发光 | 玻璃、饮料、香水 | 光源位于后方，保留边缘和内部折射 |
| 顶光 | 强调顶部结构和投影 | 平铺、食品、俯拍 | 顶部大柔光或定向硬光 |
| 高调光 | 明亮、干净、轻盈 | 白底图、清洁护理 | 明亮背景、低对比、细节不过曝 |
| 低调光 | 深色、神秘、厚重 | 数码、珠宝、奢华视觉 | 暗背景、局部高光、暗部仍保留结构 |
| 三点布光 | 主体立体、层次稳定 | 人物、服装、复杂商品 | 主光塑形、补光控反差、轮廓光分离 |
| 窗光 | 自然、生活化 | 家居、食品、服装 | 单侧大面积柔光，阴影方向明确 |
| 黄金时刻 | 暖色、长阴影 | 户外生活方式图 | 低角度暖光、长而柔的投影 |

三点布光通用指令：

~~~text
使用经典三点布光：主光位于相机左前方 45 度、略高于主体，负责塑造主要体积；补光位于相机右前方，强度明显低于主光，只用于抬起暗部；轮廓光位于主体后上方，沿外轮廓形成窄高光，使主体与背景分离。三束光色温协调，不产生互相矛盾的多重阴影。
~~~

商品三点布光示例：

~~~text
为黑色磨砂耳机制作暗调棚拍图。左前方大柔光箱为主光，表现耳罩弧面和磨砂颗粒；右前方极弱补光保留暗部结构；后上方窄条轮廓光勾勒头梁和耳罩边缘。背景为深灰到黑色的平滑渐变，产品下方有短而柔的接触阴影。保持商品结构、接口、Logo 和材质不变。
~~~

<a id="shadow-control"></a>
## 3. 阴影方向、软硬、长度与颜色

阴影至少有五个可控制属性：

1. **方向：** 与主光方向相反。
2. **长度：** 受光源高度影响；低角度光形成长阴影，顶光形成短阴影。
3. **软硬：** 大面积近距离光源通常更柔，小面积远距离直射光通常更硬。
4. **深浅：** 接触处最深，向外逐渐变淡；补光越强，阴影越浅。
5. **颜色：** 阴影会受到环境光影响，不一定是纯黑。

定位光源的方法：

- “主光从左上方进入，所有投影统一向右下方延伸。”
- “光源位于画面十点钟方向，产品投影落向四点钟方向。”
- “低角度夕阳从右后方照射，形成向左前方延伸的长阴影。”
- “正午顶光，阴影短而集中在产品底部附近。”

阴影微调短句：

- “阴影太长，只缩短投影长度，方向和软硬保持不变。”
- “阴影边缘过硬，把外缘变柔，接触处仍保持较清晰。”
- “阴影太黑，增加环境补光，让暗部保留材质细节。”
- “阴影方向错误，改为与左上方主光相反的右下方向。”
- “产品像悬浮，增加紧贴底部的短接触阴影，再向外柔和过渡。”
- “地面为暖色木材，让阴影带轻微暖色反射，不要使用纯黑色块。”
- “玻璃阴影应包含透光和轻微颜色变化，不要画成不透明实体阴影。”

完整阴影指令：

~~~text
主光从画面左上方照射，产品投影向右后方延伸。底部接触阴影最深且边缘较清晰，离开接触点后逐渐变软、变浅，长度约为产品高度的一半。阴影中保留地面暖色环境反射，不要出现第二组方向冲突的阴影。
~~~

<a id="material-lighting"></a>
## 4. 材质与光线的关系

光影必须匹配材质：

- **布料、木材、未上釉陶瓷：** 漫反射为主，高光宽而弱，纹理通过侧光显现。
- **抛光金属：** 反射清晰，高光形状接近光源形状；要描述周围环境的反射来源。
- **拉丝金属：** 高光沿拉丝方向延展，可使用“各向异性反射、细长高光”。
- **亮面塑料：** 有明确镜面高光，但反射通常不如镜面金属强。
- **磨砂塑料：** 高光较宽、反射模糊，表面细腻均匀。
- **透明玻璃：** 依靠边缘高光、折射、内部反射和背景畸变表现体积。
- **磨砂玻璃：** 半透明、散射背景细节，边缘仍有透光。
- **玉石、蜡、皮肤等半透材质：** 可使用次表面散射描述光进入表面后的柔和扩散。
- **织物和皮革：** 侧光显示织纹、绒毛、压纹和褶皱；不要把所有表面都画成塑料高光。

玻璃饮料示例：

~~~text
透明玻璃杯中装有带冰块的琥珀色饮料，强烈但受控的逆光从杯后方穿过液体。杯壁有清晰边缘高光、真实折射和内部反射，冰块透亮但不过曝；液体颜色在厚处更深、薄处更亮。桌面保留轻微彩色透光阴影。不要把玻璃画成白色实体或塑料。
~~~

针织服装示例：

~~~text
保持人物和针织毛衣的版型、颜色、织法与图案不变。使用右侧窗户的大面积柔光，以斜侧光显示纱线纹理、罗纹和自然褶皱；高光柔和，不产生塑料般的镜面反射。暗部仍能看见织纹，人物面部和背景不变。
~~~

<a id="composition-canvas"></a>
## 5. 产品构图、画布与尺寸参照

构图要写清楚：

- 画布比例：1:1、4:5、3:4、16:9、9:16 等。
- 主体占比：主体宽度或高度约占画布百分比。
- 位置：居中、偏左、偏右、下三分之一等。
- 机位：眼平、俯拍、顶视、低机位、三分之四视角。
- 留白：为标题、价格、按钮或卖点预留位置。
- 裁切：完整展示、半身、特写，哪些部位不能被裁掉。
- 透视：广角感、标准视角、中长焦压缩或正交展示感。

通用指令：

~~~text
使用 4:5 竖版画布，商品位于画面下方中央，高度约占画布 68%，完整展示且不裁切。画面右上方保留约 25% 的干净负空间供后期文案使用。采用略高于商品的三分之四视角，保持自然透视，不使用夸张广角畸变。
~~~

尺寸参照只在参照物尺寸可靠时使用。推荐公式：

~~~text
[商品及真实尺寸] + [常见参照物及尺寸] + [两者比例关系] + [视角与摆放] + [光影] + [不变约束]
~~~

示例：

~~~text
展示折叠后的雨伞与长度约 15 厘米的常见智能手机并排平放，雨伞略长于手机。使用顶视角，两个物体位于同一水平面、距离相近，避免透视造成错误尺寸感。保持雨伞结构、颜色、Logo 和所有部件不变。
~~~

注意：

- 不要使用尺寸不稳定的参照物，例如“一个人的手”而不说明年龄和近似尺寸。
- 参照物和商品必须处于相近景深和平面，避免近大远小误导。
- AI 生成的尺寸对比不能代替真实测量，最终尺寸信息必须以商品数据为准。

<a id="scene-compositing"></a>
## 6. 场景合成与环境锚定

场景合成公式：

~~~text
产品事实 + 环境类型 + 空间位置 + 接触面 + 对象关系 + 主光方向 + 环境反射 + 透视尺度 + 景深层次 + 色彩氛围 + 锁定项
~~~

推荐顺序：

1. 指明原图和产品参考各自职责。
2. 描述产品位于什么表面或空间。
3. 描述产品与背景、道具、人物的前后左右关系。
4. 明确主光从哪里来，产品如何接受同一光源。
5. 描述接触阴影、环境反射、透视尺度和景深。
6. 锁定商品结构、文字、Logo、颜色和材质。
7. 禁止带入参考图的无关元素。

完整模板：

~~~text
使用图 1 的商品作为主体，准确保留其结构、比例、颜色、材质、Logo、文字和关键细节。把商品放入 [环境]，位于 [具体位置和接触面]，与 [人物/道具] 保持 [前后左右、距离、遮挡和比例关系]。

环境主光从 [方向] 照射，性质为 [软硬、强度、色温]。商品必须接受同一主光，在 [方向] 形成 [长度、软硬、深浅] 的接触和投射阴影，并反射周围 [颜色/物体] 的环境色。商品和场景使用一致的透视、焦点、景深、噪声和色彩分级。

不要改变商品设计，不要新增不存在的接口、文字或配件；不要带入参考图中的原背景和无关道具。
~~~

<a id="natural-light-templates"></a>
## 7. 自然光与氛围模板

**清晨柔光**

~~~text
清晨的柔和自然光从左侧大窗进入，色温中性略暖，低对比，阴影较长但边缘柔和。空气清透，背景亮度逐渐过渡，商品表面保留细腻纹理和轻微环境反射。
~~~

**正午直射光**

~~~text
接近正午的高角度日光，亮度高、方向明确，形成短而清晰的投影。控制高光不过曝，暗部有少量环境补光，画面清爽、有活力。
~~~

**黄金时刻**

~~~text
低角度暖色夕阳从右后方照射，形成金色轮廓光和向左前方延伸的长阴影。暗部受到较冷环境光补充，形成自然的暖冷层次。
~~~

**室内窗光**

~~~text
单侧大窗柔光从画面左侧进入，光线由亮到暗自然衰减。靠窗一侧高光柔和，背光侧有弱环境补光，接触阴影真实，整体像自然生活方式摄影。
~~~

**阴天漫射光**

~~~text
均匀的阴天漫射光，方向性弱、对比低、阴影柔和，色温偏中性冷。保持材质纹理和颜色准确，避免灰雾和低饱和导致商品失去层次。
~~~

氛围词要服务于具体光线。可使用“清透、安静、温暖、清爽、戏剧性、克制、明亮”等，但必须与方向、色温和对比描述配套。

<a id="structure-lock"></a>
## 8. 结构锁定与负向约束

优先用正向事实锁定，再补充禁止变化项：

~~~text
保持产品外形、尺寸比例、开孔、按键、连接处、Logo、标签、纹理和颜色分区完全准确；使用自然的标准透视和三分之四视角。只重建场景与匹配光影，不得拉伸、压缩、弯曲、复制或增删产品部件。
~~~

负向补充：

~~~text
不要新增文字、价格标签、装饰、包装或重复产品；不要产生广角拉伸、边缘翘曲、错误反射、双重阴影、悬浮或穿模。
~~~

注意：

- “no distortion”过于笼统，应同时写出正确轮廓、比例和视角。
- “85mm”可表达较自然的中长焦透视感，但不保证绝对防畸变。
- 人体结构也应优先描述正确姿态和手部动作，再补充“不要多指或肢体粘连”。
- 并非所有模型都有独立负向提示词栏；不支持时，把禁止项写入自然语言末尾。

<a id="sku-variants"></a>
## 9. SKU 换色与批量变体

换色使用“三层结构”：

~~~text
目标颜色 + 材质锁定 + 原有光影继承
~~~

完整模板：

~~~text
只把 [目标部件] 的基础色从 [原色] 改为 [目标色/色值]。保持原有材质、表面纹理、粗糙度、透明度、缝线、Logo、文字、颜色分区、结构和比例不变。新的颜色必须继承原图的高光、阴影、反射和环境色；不要把目标颜色扩散到人物、背景或其他部件。
~~~

双色或多色模板：

~~~text
只修改服装颜色：主体面料改为深黑色，滚边和指定装饰区域改为暗红色。颜色分区边界严格沿原有缝线和裁片，不改变版型、针织纹理、褶皱、Logo、人物和背景。两种颜色分别继承原有光照明暗，不要互相渗色。
~~~

批量变量表建议：

| 字段 | 固定项 | 变量 |
|---|---|---|
| 商品结构 | 固定 | 不变 |
| 材质和纹理 | 固定 | 不变 |
| Logo 和文字 | 固定 | 不变 |
| 构图和光影 | 固定 | 可按实验设计控制 |
| SKU 颜色 | 变量 | 每次只填一个标准名称或色值 |
| 背景 | 固定或变量 | 与实验目的保持一致 |
| 输出命名 | 固定规则 | SKU、场景、版本、序号 |

<a id="grid-selection"></a>
## 10. 九宫格测试与快速选片

九宫格适合快速比较光位、角度、场景或构图，但每格细节有限。先用于方向探索，选中后再单独生成高分辨率版本。

九种光位测试模板：

~~~text
创建一个干净的 3×3 九宫格，九个等大画面都使用同一个商品，准确保持其外形、比例、颜色、材质、Logo 和身份一致。所有格子使用相同的画布、机位、背景和商品占比，只改变打光方式：

1. 正面均匀柔光
2. 左前方 45 度主光
3. 右前方 45 度主光
4. 顶部柔光
5. 强轮廓光
6. 透明材质逆光
7. 明亮高调光
8. 深色低调光
9. 暖色黄金时刻光

每格下方留空，不生成文字或编号。九格中的商品不得变形、换色、增减部件或改变拍摄角度。整体为专业商品摄影测试板。
~~~

九种镜头与构图测试可使用：

1. 正面主图。
2. 三分之四角度。
3. 顶视。
4. 低机位。
5. 细节特写。
6. 等距视角。
7. 悬浮构图。
8. 带手部互动。
9. 环境宽景。

选片标准：

- 商品真实性优先于气氛。
- 光线是否真正展示卖点材质。
- 阴影和接触关系是否可信。
- 构图是否适合实际版位。
- 选中后重新用单场景指令生成，不直接把九宫格小图当最终素材。

<a id="reference-fusion"></a>
## 11. 参考图融合

不要只写“其余保持 90% 相似”。应把相似性拆成可检查字段：

~~~text
图 1 提供商品结构、颜色、材质、Logo 和细节；图 2 只提供场景构图、相机位置、主体占比和光影气氛。生成结果必须保留图 1 的商品事实，并沿用图 2 的空间布局。不要复制图 2 中的原商品、文字、品牌或无关道具。
~~~

如果工具支持参考强度：

- 高参考强度通常更接近参考图，但可能减少变化空间。
- 低参考强度允许更多创作，但商品或构图更容易漂移。
- 数值含义因工具不同，不建立跨工具统一刻度。
- 先固定提示词，只调整一个权重；每次保存参数和结果。
- 即使有权重，也必须写清每张参考图的职责和优先级。

<a id="outpaint-upscale"></a>
## 12. 扩图、放大与瑕疵修复

**扩图**

~~~text
把画布从 [原比例] 扩展到 [目标比例]，原图主体的位置、大小、结构、光线和颜色保持不变。只延展 [方向] 的背景，延续原有透视、墙面/地面纹理、光照梯度、景深和噪声。不要复制主体，不要在扩展区域新增无关物体。
~~~

**放大**

~~~text
在保持原始构图、比例、颜色、风格和主体身份不变的前提下提高分辨率。恢复真实且与原图一致的边缘、发丝、织物、金属、玻璃和皮肤细节；不要凭空添加文字、纹理、毛孔、饰品或产品结构。清除压缩块、锯齿和轻微噪点，但保留自然质感。
~~~

**局部修复**

~~~text
只修复 [具体区域] 的 [模糊/锯齿/纹理断裂/边缘光晕]。参考相邻区域恢复连续的颜色、纹理方向、光照和噪声。其他区域保持像素级视觉一致，不要重新生成整个主体。
~~~

“4K、8K、ultra detailed”只是输出意图，不保证真实分辨率或新增细节正确。应确认工具是否支持原生尺寸、放大倍率或导出规格，并在放大后逐项复核文字和结构。

<a id="failure-correction"></a>
## 13. 常见失败与修正

| 问题 | 原因 | 修正指令 |
|---|---|---|
| 主体漂浮 | 缺少接触阴影 | “在底部增加短而深的接触阴影，向外逐渐变软。” |
| 双重阴影 | 多个光源逻辑冲突 | “保留一个主投影方向，辅光只抬暗部，不产生第二个明显投影。” |
| 金属像塑料 | 反射和粗糙度不明确 | “恢复拉丝方向、各向异性高光和环境反射，不使用均匀塑料亮斑。” |
| 玻璃变白 | 缺少透光和折射 | “保持透明度、边缘高光、背景折射和内部反射。” |
| 产品结构变了 | 场景描述优先级太高 | “商品事实优先级最高，只调整环境与光影。” |
| 尺寸对比误导 | 参照物不可靠或不在同一平面 | 使用明确尺寸，保持相近距离与透视，并人工标注真实数据。 |
| 换色污染背景 | 未限定部件边界 | “颜色变化严格限制在原有裁片/外壳分区内。” |
| 九宫格商品不一致 | 同时变化太多 | 固定商品、角度、背景和构图，只改变一种变量。 |
| 放大后出现假细节 | 模型自由补画 | “不新增原图不可见的结构、文字和纹理，只恢复已有信息。” |
| 扩图出现重复主体 | 未限制扩展区 | “只延展背景，不复制人物、商品或道具。” |

## 14. 可复制提示词模板

**商品场景图**

~~~text
为 [商品] 创建 [场景]。商品位于 [位置和接触面]，画布 [比例]，采用 [机位和景别]，主体占比约 [百分比]，在 [位置] 保留文案空间。

主光从 [方向] 照射，为 [软硬、强度、色温]；补光 [描述]；轮廓光 [描述]。投影向 [方向]，接触处 [深浅和软硬]，商品反射 [环境颜色和物体]。

准确保持商品的结构、比例、颜色、材质、Logo、文字和所有关键部件，不新增或删除任何商品事实。输出 [规格]。
~~~

**透明材质图**

~~~text
为 [玻璃/透明包装/液体] 创建 [场景]。使用后方逆光和两侧窄边缘光，显示真实透明度、折射、内部反射、液体层次和边缘厚度。背景简洁且与透明主体有足够明度或色彩分离。保留真实接触阴影和轻微透光颜色，不要把透明材质画成白色实体。
~~~

**暗调数码图**

~~~text
保持商品结构和表面准确，在深灰至黑色背景中使用低调棚拍光。左前方窄柔光表现主要曲面，后方轮廓光分离外形，暗部仍保留接口、按键和纹理。产品下方有短接触阴影，金属或塑料反射均有明确光源，不出现无来源亮斑。
~~~

<a id="checklist"></a>
## 15. 验收清单

- [ ] 主光方向与投影方向一致。
- [ ] 光线软硬、强度、色温和对比符合场景。
- [ ] 产品接触面有合理阴影，不漂浮、不穿模。
- [ ] 金属、玻璃、织物、塑料的光学表现没有串材质。
- [ ] 画布比例、主体占比、裁切、留白和安全区正确。
- [ ] 尺寸参照物可靠，商品与参照物透视一致。
- [ ] 商品结构、数量、文字、Logo、纹理和反射未被场景重绘。
- [ ] SKU 换色只改变授权区域并保留材质光影。
- [ ] 九宫格只用于探索，入选方向已单独生成并验收。
- [ ] 扩图没有复制主体，放大没有虚构新细节。
- [ ] 已保存提示词、参考图、参数、候选和选片理由。
