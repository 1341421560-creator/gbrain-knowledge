# AI 产品视频：故事板、复合运镜、连续性剪辑与可灵工作流

[返回知识库导航](../../知识库导航.md)

> **重点：** 高质量 AI 产品视频不是把“电影感、微距、运镜、转场”堆进一条提示词，而是先锁定商品事实，按剪辑节奏设计静态故事板，再把每个镜头写成“进入—展示—离开”的运动曲线，并在相邻镜头之间建立方向、速度、构图、焦点和声音连续的运动接口。本文适用于使用商用云端视频模型制作产品广告，重点说明可灵 VIDEO 3.0 的参考图、首尾帧、自定义多镜头和后期剪辑工作流。

<a id="core-conclusions"></a>
## 1. 核心结论

- 产品视频先写剪辑脚本，再写生成提示词；镜头存在的理由是传递信息、情绪或节奏，而不是展示模型会运镜。
- “一个镜头只能有一个运镜”过于保守。更准确的规则是：一个镜头只有一个明确的视觉意图和主运动轴，但可以包含按时间排列的多个运动阶段，或由一个主运动带一至两个克制的辅助运动。
- 镜头尾部必须设计“出场接口”，下一镜头开头必须设计“入场接口”。方向、速度、加速度、构图、焦点、形状、光线或声音至少匹配三项，切换才容易自然。
- 商品真实性优先于气氛。产品形状、比例、颜色、材质、Logo、文字和部件边界应由原始商品图、CAD、3D 渲染或实拍资料提供，不能让模型自由补全关键事实。
- 微距进入内部零件时，最稳的路径是“完整产品 → 表面细节 → 接口或缝隙 → 遮挡或暗部 → 内部零件 → 功能状态 → 返回英雄镜头”。
- 可灵的首尾帧适合相似画面之间的可解释运动；场景、结构或产品状态变化过大时，应拆成独立镜头并使用匹配剪辑，不要强迫模型做长距离变形。
- 商用成片应以逐镜头生成和人工剪辑为主；自定义多镜头适合快速预演、连续叙事或同一生成内的镜头覆盖，但不能替代产品事实核验和后期精修。

<a id="scope"></a>
## 2. 适用范围与边界

- **适用对象：** 使用可灵等商用云端模型制作消费电子、美妆、汽车、家电、包装、珠宝、软件硬件组合等产品广告的个人或团队。
- **适用场景：** 15～60 秒产品广告、社交媒体短视频、电商视频、官网英雄视频、功能解释视频、概念宣传片。
- **不使用本地模型：** 工作流以云端生图、云端视频生成和非线性剪辑为基础，不依赖本地大模型。
- **不适用场景：** 必须逐毫米准确的工程演示、医疗器械内部原理、法律或安全责任重大的机械工作过程，除非已有经过审核的 CAD、3D 动画或技术资料。
- **商业边界：** 未提供或未核验的功能、认证、尺寸、性能数据和内部结构不得被表现为真实事实；概念化内部画面应明确标注为功能可视化。

<a id="production-workflow"></a>
## 3. 完整生产流程

推荐顺序：

~~~text
传播任务
→ 产品事实与参考资产
→ 视觉方向
→ 镜头节拍表
→ 静态故事板
→ 音乐和静态预剪
→ 首帧、中间关键状态、尾帧
→ 可灵逐镜头测试
→ 运动接口匹配
→ 精剪、调色、文字和声音
→ 产品事实与品牌验收
~~~

<a id="define-brief"></a>
### 3.1 先定义传播任务

生成前固定以下信息：

- 发布平台与画幅：9:16、16:9 或 1:1。
- 总时长：15 秒、30 秒或 60 秒。
- 唯一传播重点：外观、材质、核心功能、使用体验或品牌情绪。
- 目标动作：购买、预约、下载、了解新品。
- 视觉关键词：高级、科技、温暖、天然、年轻、力量等。
- 品牌硬约束：Logo、字体、标准色、禁用色、包装、文字安全区。
- 事实边界：哪些内容有实物、CAD、数据或认证支持，哪些只是概念表达。

15 秒广告通常只承担一个主要传播命题。多个卖点应按镜头节拍逐步展开，不应在一个镜头内同时解释。

<a id="product-asset-pack"></a>
### 3.2 建立产品资产包

至少准备：

- 正面、左前 3/4、右前 3/4、侧面和背面产品图。
- Logo、接口、按钮、纹理、标签和包装细节图。
- 产品实际比例、材质、颜色和不可改变部件说明。
- 内部结构的 CAD、分解图、3D 渲染或实拍资料。
- 品牌色板、字体、包装规范和标准文案。
- 目标场景、构图、光线和参考广告。
- 可灵元素库中的产品元素；必要时为产品、包装、关键部件分别建立元素。

每张参考图必须有明确职责。例如：

~~~text
图 1～4：只提供产品结构、比例、颜色、材质、Logo 和部件边界。
图 5：只提供场景构图、机位、主体占比和光影气氛。
图 6：只提供内部零件位置和工作关系。
以产品事实图为最高优先级，不复制场景参考图中的品牌、文字、商品或无关道具。
~~~

<a id="animatic-first"></a>
### 3.3 先做剪辑预演

先选音乐或临时节奏轨，标记：

- 开场冲击点。
- 产品第一次完整出现的时间。
- 卖点揭示点。
- 情绪上升点。
- 功能高潮。
- Logo 和 CTA 落点。

将静态故事板按计划时长放进剪辑软件，加入临时旁白和音效，形成 animatic。只有在静态预演中节奏成立，才进入高成本的视频生成。

<a id="storyboard-keyframes"></a>
## 4. 静态故事板与首尾帧

<a id="storyboard-vs-start-end"></a>
### 4.1 故事板关键帧与可灵首尾帧的区别

| 图片类型 | 作用 | 准确度要求 |
|---|---|---|
| 气氛故事板 | 验证叙事、色彩和节奏 | 允许产品细节有少量偏差 |
| 镜头首帧 | 规定摄像机从哪里开始 | 产品和构图必须准确 |
| 中间关键状态 | 规定复合运镜转折点 | 用于故事板和时间轴提示词 |
| 镜头尾帧 | 规定摄像机最终状态和下个镜头接口 | 产品、方向、尺度和焦点必须准确 |
| 下一镜头首帧 | 接收上一镜头的运动接口 | 必须匹配出场方向、速度感和构图 |

简单推进或横移可以只用首尾帧。包含“横移 → 环绕 → 推进 → 穿越”的镜头至少需要在故事板中设计首、中、尾三个状态；如果中间转折必须精确，应拆成两个生成镜头。

<a id="gpt-image-keyframes"></a>
### 4.2 使用 GPT 生图生成关键帧

GPT 生图可用于故事板、首帧和尾帧，但首尾帧应分别基于用户提供的原始产品参考图生成，不默认在 AI 生成图上反复迭代。

提示词按以下顺序组织：

~~~text
任务动作
→ 产品准确事实
→ 场景和空间关系
→ 构图与机位
→ 光影
→ 材质
→ 输出比例和分辨率
→ 允许变化项
→ 锁定项
→ 禁止项
→ 验收标准
~~~

OpenAI 官方说明 GPT Image 支持参考图和图片编辑，但仍可能在跨次生成的一致性、精确文字和严格构图上出现偏差。Logo、标签和法律文案应逐项验收，重要文字优先后期叠加。

<a id="keyframe-variables-locks"></a>
### 4.3 首尾帧可变项与锁定项

**允许小幅改变：**

- 摄像机位置和小角度观察方向。
- 景别远近。
- 一个可解释的产品动作。
- 焦点位置。
- 局部高光或粒子状态。

**默认锁定：**

- 产品形状、比例、颜色、材质和部件边界。
- Logo、标签、接口和按钮位置。
- 场景结构、台面纹理和主光方向。
- 产品在空间中的位置和接触阴影。
- 品牌色和整体调性。

首尾帧变化过大时，不应依靠插值强行过渡。例如室内到户外、白天到夜晚、完整产品到完全拆解、静止产品到大量爆炸变形，都更适合拆镜头。

最终只需使用 2～3 秒的镜头，可以生成 4～5 秒并保留前后余量。不要把 AI 素材的第一帧和最后一帧默认当成可用画面。

<a id="three-phase-motion"></a>
### 5.2 镜头运动三阶段

- **入镜段：** 让观众建立产品位置、尺度和运动方向。
- **主体段：** 展示本镜头的唯一信息任务，例如材质、接口或使用动作。
- **出镜段：** 不一定停稳；为了自然衔接，镜头可以在推进、横移、旋转或遮挡仍在进行时结束。

产品视频常见错误是主体展示结束后让镜头完全停止，再切到另一个正在高速运动的镜头。除非需要刻意停顿，否则应在运动仍有惯性时剪切。

<a id="compound-camera-movement"></a>
## 6. 复合运镜方法

<a id="sequential-compound-move"></a>
### 6.1 顺序式复合运镜

不同运动按时间依次接管：

~~~text
0～1 秒：低机位横向滑轨，建立轮廓。
1～3 秒：横移逐渐转为小角度顺时针环绕，展示正面。
3～5 秒：环绕运动不断，同时加速推进到产品接口；
接口填满画面，镜头结束时推进仍未停止。
~~~

顺序式复合运镜适合从完整产品逐步进入细节。提示词必须使用时间节点和过渡动词，例如“逐渐转为”“同时开始”“运动不断”“最后加速”，而不是把多个摄影术语无层级地并列。

<a id="simultaneous-compound-move"></a>
### 6.2 同时式复合运镜

一个主运动带一至两个轻微辅助运动：

~~~text
摄像机平稳向产品推进，推进是主要运动；
推进过程中轻微向右摇摄，使产品保持在画面中心；
同时小幅上仰，从底部结构逐渐揭示到顶部标志。
右摇和上仰幅度克制，不改变主要的向前运动方向。
~~~

同时式运动适合需要维持主体构图的推进、跟踪和环绕。若每个运动都被写成快速、大幅度和同等重要，模型更容易产生漂移、变焦错觉或产品变形。

<a id="primary-secondary-motion"></a>
### 6.3 主运动与辅助运动

主运动决定观众感受到的总体方向；辅助运动只负责构图修正、信息揭示或情绪强化。

| 主运动 | 合理辅助运动 | 常见用途 |
|---|---|---|
| 推进 | 轻微摇摄、轻微上仰、拉焦 | 进入 Logo、接口或纹理 |
| 横移 | 小角度环绕、焦点跟随 | 展示轮廓和材质 |
| 环绕 | 轻微推进、保持主体居中 | 展示三维结构 |
| 跟踪 | 小幅升降、摇摄修正 | 跟随人物使用产品 |
| 后拉 | 轻微升高、揭示环境 | 从细节回到英雄镜头 |

摄影参数如“85mm 焦段感、f/2.8 式浅景深”只用于表达视觉效果，不应被当作真实器材元数据。

<a id="transition-contract"></a>
## 7. 镜头衔接与运动交接协议

<a id="continuity-dimensions"></a>
### 7.1 需要匹配的连续性维度

| 维度 | 检查内容 |
|---|---|
| 方向 | 推进接推进、右移接右移、顺时针接顺时针 |
| 速度 | 切点前后的像素运动速度是否接近 |
| 加速度 | 前镜在加速时，后镜不能突然慢下来 |
| 构图 | 关键产品或零件是否处在接近的位置 |
| 尺度 | 接口、Logo或圆形零件在两帧中的大小是否接近 |
| 焦点 | 观众视线是否从上一帧自然落到下一帧 |
| 形状 | 圆接圆、线接线、边缘接边缘 |
| 光线 | 亮度、色温、高光方向是否连续 |
| 声音 | 机械声、气流声、音乐或旁白是否跨过切点 |

相邻镜头最好至少匹配三项。最强的基础组合是“方向 + 速度 + 构图 + 声音”。

<a id="push-to-push"></a>
### 7.2 推进接推进

镜头 A 结尾：

~~~text
摄像机继续向画面中央的圆形接口推进，
接口从画面 30% 扩大到填满画面；
推进速度中等并持续加快，冷蓝高光位于接口中心；
镜头在运动尚未停止时结束。
~~~

镜头 B 开头：

~~~text
画面从相同位置和大小的圆形内部通道开始，
摄像机以接近上一镜头的速度继续向内部推进；
通道边缘短暂形成暗色遮挡，随后进入产品内部空间。
~~~

切点应落在运动最明显、画面接近遮挡或模糊的位置，而不是两边都完全静止的清晰帧。

<a id="hidden-cuts"></a>
### 7.3 常用隐藏切点

- **推进穿越：** 从接口、孔洞、Logo、镜片或纹理推进到另一个空间。
- **前景遮挡：** 产品边缘、手、包装、阴影、布料、烟雾或液体盖满画面。
- **甩镜与运动模糊：** 前镜快速向右形成模糊，后镜从同方向模糊开始并逐渐减速。
- **动作匹配：** 产品旋转、开盖、液滴下落或手部动作跨镜头继续。
- **图形匹配：** 圆形按钮切到圆形机芯，边缘线切到内部轨道。
- **颜色匹配：** 蓝光、黑场、高光或粒子方向跨镜头连续。
- **声音桥：** 下一镜头声音提前出现，或上一镜头声音延续到下一画面。

明显特效转场应少量使用。高级产品广告多数依赖镜头内部运动和剪辑点本身，而不是转场插件。

<a id="macro-internal-components"></a>
## 8. 微距、内部零件与功能可视化

<a id="outside-inside-function"></a>
### 8.1 外—内—功能—外结构

推荐叙事链：

~~~text
完整产品英雄镜头
→ 表面材质微距
→ 关键接口或缝隙
→ 推进、遮挡或暗部穿越
→ 内部零件全貌
→ 核心零件工作特写
→ 功能结果或能量路径
→ 后拉回到完整产品与品牌定帧
~~~

微距镜头不是单纯放大。必须说明：

- 镜头观察的具体部件。
- 部件相对产品的位置。
- 材质、纹理和反射边界。
- 焦点从哪里移动到哪里。
- 产品边缘、文字或接口是否必须保持清晰。
- 镜头如何从微距状态进入下一层结构。

<a id="internal-truth-boundary"></a>
### 8.2 内部结构真实性边界

如果内部结构是产品事实，需要提供：

- CAD、3D 渲染或结构分解图。
- 实际内部照片。
- 零件名称、数量、位置和连接方式。
- 正确的旋转、滑动、开合或能量传递方向。
- 允许简化和禁止虚构的部分。

没有这些资料时，只能制作概念化功能可视化，不应表现为真实内部构造。模型生成的齿轮、芯片、线圈和光路可能视觉可信但工程错误。

<a id="kling-workflow"></a>
## 9. 可灵 VIDEO 3.0 工作流

<a id="single-vs-multishot"></a>
### 9.1 单镜头、独立生成与多镜头的选择

| 方式 | 适合场景 | 风险 |
|---|---|---|
| 单镜头图生视频 | 精确产品外形、宏观运镜、微距细节 | 复杂转折可能漂移 |
| 独立镜头逐条生成 | 商用广告、精确剪辑、内部结构 | 需要人工设计连续性 |
| 首尾帧生成 | 相似构图之间的明确运动 | 差异过大会变形或自行切镜 |
| 自定义多镜头 | 快速预演、连续叙事、同场景覆盖 | 单个镜头和品牌细节仍需验收 |
| 长镜头时间轴 | 连续空间、分阶段复合运镜 | 时间点和复杂动作具有概率性 |

截至 2026-07-29，可灵 VIDEO 3.0 支持 3～15 秒、多镜头、自定义多镜头、参考元素和原生音频。自定义多镜头可以逐镜头定义时长、景别、视角、叙事内容和摄影机运动；当前官方说明单次最多可规划 6 个镜头。平台能力、价格和菜单可能变化，使用时应重新核验。

<a id="timeline-prompt-template"></a>
### 9.2 时间轴提示词模板

~~~text
[时长]，单一连续镜头，无剪切。

产品：
[产品准确结构、材质、颜色、Logo、位置和不可变特征]

场景：
[前景、中景、背景、台面、空间和光线]

0～20%：
[起始景别、机位和入镜运动]

20～75%：
[主运动、辅助运动、主体动作和焦点变化]

75～100%：
[为下个镜头设计的出场运动，明确方向、速度、尺度和结束状态]

镜头结束时：
[运动继续/逐渐减速/遮挡填满画面]
[下一个镜头应该接收的形状、光线、焦点和声音]

必须保持：
[产品结构、比例、Logo、材质、部件边界]

禁止：
[变形、多余产品、错误文字、突然切镜、反向运动、背景闪烁]
~~~

提示词应使用可见结果和空间关系，不只写“电影感”“高级运镜”。一个主运动可以配合辅助运动，但必须说明主次、时间和目的。

<a id="reference-elements"></a>
### 9.3 参考元素与一致性

- 使用多角度产品图建立元素，锁定产品形状、颜色和身份。
- 内部零件可单独建立元素，但必须来自真实资料。
- 在提示词中继续描述元素在场景中的角色，不要以为绑定元素后无需说明位置、动作和构图。
- 参考图负责产品事实，场景图负责构图与光线，内部结构图负责零件关系；发生冲突时产品事实优先。
- 先用较低成本设置测试运动，再用高质量设置生成最终候选；每次只改变速度、运动幅度或构图中的一个主变量。

<a id="editing-method"></a>
## 10. 后期剪辑方法

<a id="cut-speed-match"></a>
### 10.1 切点与速度匹配

1. 将镜头 B 放在镜头 A 上方。
2. 临时把 B 的不透明度降低到约 50%。
3. 对齐接口、圆心、Logo、零件或高光位置。
4. 调整 B 的缩放和位置，使切点前后构图接近。
5. 使用速度重映射匹配推进、横移或旋转速度。
6. 在运动中切，不等待动作或摄影机完全停止。
7. 必要时只在模糊帧或暗部遮挡之间加入极短融合。
8. 保留每条生成素材前后约 0.5～1 秒的剪辑余量。

动作匹配剪辑的关键不是使用转场效果，而是让第二个镜头继续第一个镜头的运动逻辑。

<a id="visual-audio-match"></a>
### 10.2 构图、颜色和声音匹配

- 使用叠加和示波器匹配亮度、黑位、白平衡和高光方向。
- 如果镜头景别变化不明显，应改变角度、尺度或信息层级，避免无意跳切。
- 保持观众视线位置连续：上一镜头焦点在画面右下，下一镜头关键部件也应优先出现在附近。
- 使用 J-cut 让下一镜头的声音提前进入，或使用 L-cut 让上一镜头声音延续。
- 产品动作必须有对应拟音，例如开盖、按钮、金属摩擦、液滴、气流和机械运行声。
- 重要 Logo、价格、型号、CTA 和免责声明优先在后期排版，不依赖生成视频中的文字。

<a id="quality-control"></a>
## 11. 质量验收与失败诊断

<a id="per-shot-check"></a>
### 11.1 逐镜头验收

- 产品结构、比例、颜色、材质、Logo和标签是否准确。
- 镜头任务是否清楚，是否展示了计划中的唯一信息。
- 主运动和辅助运动是否有层级。
- 焦点、景深、反射、阴影和接触关系是否可信。
- 是否存在融化、闪烁、多余产品、错误部件或背景漂移。
- 出场接口的方向、速度、尺度和构图是否可用于下一镜头。
- 是否保留可剪辑余量。

<a id="cross-shot-check"></a>
### 11.2 跨镜头验收

- 相邻镜头的方向、速度、加速度是否连续。
- 产品和关键零件在画面中的位置是否合理。
- 主光方向、色温、黑位和高光是否突然变化。
- 运动中的旋转方向和产品动作阶段是否匹配。
- 上一镜头的视线落点是否对应下一镜头的关键区域。
- 声音是否跨过切点支撑连续性。
- 连续观看时是否感觉镜头有信息推进，而不是同一画面的重复角度。

<a id="failure-fixes"></a>
### 11.3 常见失败与修正

| 失败 | 常见原因 | 修正 |
|---|---|---|
| 复合运镜混乱 | 多个运动同等强度、无时间顺序 | 设一个主运动，按阶段写辅助运动 |
| 产品在推进中变形 | 参考角度不足或推进跨度过大 | 增加多角度产品图，拆镜头 |
| 两个推进镜头仍有跳感 | 速度、中心或尺度不匹配 | 叠加对齐并做速度重映射 |
| 首尾帧中间融化 | 首尾结构、场景或光线差异过大 | 缩小变化或独立生成后剪辑 |
| 内部零件可信但错误 | 模型自由补全真实结构 | 提供 CAD/分解图，或标为概念可视化 |
| 微距画面没有高级感 | 只放大，没有材质、焦点和光线设计 | 指定部件边界、焦点轨迹和高光行为 |
| 转场显得模板化 | 依赖插件而非镜头运动 | 重新设计遮挡、动作或图形匹配 |
| Logo和文字漂移 | 让模型反复重绘品牌元素 | 使用原始资产并在后期叠加 |

<a id="worked-example"></a>
## 12. 可复用示例：从产品外观推进到内部零件

<a id="example-shot-one"></a>
### 12.1 镜头一：外观到接口

~~~text
【镜头任务】
从完整产品自然推进到正面圆形接口，为进入内部结构建立运动接口。

【运动】
0～1 秒：低机位左前方 3/4 中近景，摄像机从左向右缓慢横移。
1～3 秒：横移逐渐转为顺时针小角度环绕，同时开始稳定推进；
圆形接口逐渐移动到画面中央。
3～5 秒：摄像机沿接口中心加速推进，焦点锁定接口内部；
接口从画面约 30% 扩大到完全填满画面。
镜头结束时推进运动继续，不减速、不停止。

【出场接口】
方向：向画面内部。
速度：中速并持续加快。
构图：圆形接口居中并填满画面。
焦点：接口中央。
颜色：冷蓝高光，周围逐渐变暗。
声音：机械声和低频气流声增强。
~~~

<a id="example-shot-two"></a>
### 12.2 镜头二：接口到内部

~~~text
【镜头任务】
接收上一镜头推进运动，穿过接口进入真实内部零件空间。

【运动】
0～1 秒：从与上一镜头相同大小和位置的圆形通道开始，
以接近上一镜头的速度继续向内部推进；
通道边缘短暂形成暗色遮挡。
1～3 秒：摄像机穿过通道进入内部空间，
推进逐渐转为轻微向下俯视；
焦点从通道边缘平滑转移到核心零件。
3～5 秒：摄像机沿核心零件向右进行微距跟踪，
内部零件依照参考资料中的真实方向运行，
冷蓝高光沿金属边缘移动。

【入场匹配】
方向、速度、圆形构图、冷蓝高光和机械声音与上一镜头连续。
切点放在暗色遮挡和运动最明显的位置。
~~~
