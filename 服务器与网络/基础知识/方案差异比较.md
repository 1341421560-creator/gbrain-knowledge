<a id="core-conclusions"></a>
## 1. 核心结论

- AmneziaWG 官方客户端通常比 Clash Verge TUN 更快，Clash Verge/Mihomo 的价值是分流。
- AmneziaWG 不是普通 WireGuard 配置，它需要支持混淆参数的客户端或 Mihomo core。
- 商用节点比自建节点快，通常快在线路、中转和调度，不是单纯快在协议。

## 3. 主要比较

<a id="section-linux-vps-与-windows-server"></a>
### Linux VPS 与 Windows Server

| 比较维度 | Linux VPS | Windows Server |
|---|---|---|
| 核心作用 | 命令行、脚本、服务部署 | 图形桌面、Windows 软件 |
| 成本 | 通常更低 | 通常更高，有授权成本 |
| 低配表现 | 适合轻量服务 | 低配桌面容易卡 |
| 当前建议 | 当前工程继续用 Ubuntu | 只有必须用 Windows 软件时再考虑 |

<a id="section-xorg-与-xvnc"></a>
### Xorg 与 Xvnc

| 比较维度 | Xorg | Xvnc |
|---|---|---|
| 核心作用 | 接近真实显示器的图形环境 | VNC 创建的虚拟桌面 |
| 适合场景 | 本地显示器或某些远程桌面方案 | 无显示器 VPS 的远程桌面 |
| 当前建议 | 非必要不优先 | 当前 VNC 场景更适合 |

<a id="section-本地-nvme-与块存储"></a>
### 本地 NVMe 与块存储

| 比较维度 | 本地 NVMe | 块存储 |
|---|---|---|
| 性能 | 通常更快 | 取决于服务商和网络 |
| 管理 | 跟当前服务器绑定更紧 | 可扩容、可挂载、独立管理 |
| 成本 | 常包含在套餐内 | 通常额外计费 |
| 当前建议 | 普通 VPS 优先用自带 NVMe | 数据盘扩容或迁移需求再考虑 |

<a id="section-wireguard-与-amneziawg"></a>
### WireGuard 与 AmneziaWG

| 比较维度 | WireGuard | AmneziaWG |
|---|---|---|
| 核心作用 | 快速稳定 VPN 隧道 | 带混淆参数的 WireGuard 类隧道 |
| 客户端兼容 | 普通 WireGuard 客户端支持 | 需要 AmneziaWG 客户端或 Mihomo 支持 |
| 配置特征 | 无 `Jc/S1/H1` 等混淆参数 | 包含 `Jc/Jmin/Jmax/S1-S4/H1-H4` |
| 当前用途 | 历史 `wg0`，端口 `51820` | 当前主用 `awg0`，端口 `51821` |

<a id="section-amneziawg-官方客户端与-clash-verge-tun"></a>
### AmneziaWG 官方客户端与 Clash Verge TUN

| 比较维度 | AmneziaWG 官方客户端 | Clash Verge / Mihomo TUN |
|---|---|---|
| 核心作用 | 全局 VPN | 按规则分流 |
| 性能 | 通常更快，路径更短 | 多规则处理，可能更慢 |
| 国内网站 | 全局走马来西亚会慢 | 可设置国内直连 |
| 适用场景 | 只访问国外或需要最高速度 | 日常国内外混合上网 |

<a id="section-小火箭节点与当前-amneziawg-节点"></a>
### 小火箭节点与当前 AmneziaWG 节点

| 比较维度 | 小火箭常见节点 | 当前 AmneziaWG 节点 |
|---|---|---|
| 常见协议 | SS、Trojan、VLESS、Hysteria2、TUIC | AmneziaWG |
| 配置形式 | `ss://`、`trojan://`、订阅链接 | YAML 或 `.conf` |
| 通用性 | 更适合分享和多客户端 | 客户端支持较少 |
| 当前定位 | 通用代理体验 | 稳定 VPN 隧道和 Mihomo 分流节点 |
