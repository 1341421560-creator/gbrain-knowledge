<a id="core-conclusions"></a>
## 1. 核心结论

- 需要最高全局速度时选官方 AmneziaWG；需要国内直连、国外代理时选 Clash Verge/Mihomo 分流。
- 是否删除普通 WireGuard 取决于旧客户端是否还需要 `wg0`；删除 `wg0` 不影响 `awg0`，但会影响旧 WireGuard 用户。
- 提升线路质量优先换更近或更优线路服务器，其次做中转，最后才是协议和 MTU 微调。

## 2. 适用范围

- **适用对象：** 当前自建 Hostinger 马来西亚 VPS、AmneziaWG、Clash Verge/Mihomo 和后续线路升级。

## 3. 决策主题

<a id="section-日常上网用官方-amneziawg-还是-clash-verge"></a>
### 日常上网用官方 AmneziaWG 还是 Clash Verge？

#### 目标与约束

- **目标：** 同时兼顾速度和国内外访问体验。
- **约束：** 官方 AmneziaWG 全局速度较好，但国内网站会绕路；Clash Verge 可分流，但 TUN 多一层处理。

#### 可选方案

| 方案 | 优势 | 代价 |
|---|---|---|
| 官方 AmneziaWG | 路径短，通常更快 | 全局走马来西亚，国内网站慢 |
| Clash Verge 系统代理 | 浏览器分流轻量 | 只覆盖遵守系统代理的软件 |
| Clash Verge TUN | 可覆盖更多应用 | 比官方客户端慢，规则更复杂 |

#### 推荐方案

- 只访问国外或追求最高速度时，使用官方 AmneziaWG。
- 日常国内外混合上网时，使用 Clash Verge/Mihomo 分流。
- 只浏览器需要分流时，优先开系统代理，不一定开 TUN。

<a id="section-是否删除普通-wireguard"></a>
### 是否删除普通 WireGuard？

#### 目标与约束

- **目标：** 减少不再使用的旧服务。
- **约束：** `wg0` 和 `awg0` 独立，删除 `wg0` 不影响 AmneziaWG，但会影响旧 WireGuard 客户端。

#### 推荐方案

先停用而不是直接删除：

```bash
systemctl stop wg-quick@wg0
systemctl disable wg-quick@wg0
```

确认没有旧客户端需要 `10.8.0.2/32` 和 `51820/UDP` 后，再考虑删除配置和软件。

<a id="section-如何提升当前线路质量"></a>
### 如何提升当前线路质量？

#### 目标与约束

- **目标：** 降低延迟、减少卡顿、提高稳定性。
- **约束：** 当前服务器出口很快，瓶颈主要在本机到马来西亚 Hostinger 的线路。

#### 可选方案

1. 换更近服务器：香港、日本、新加坡、台湾、韩国。
2. 买优化线路：CN2 GIA、CMI、BGP 优化、三网优化。
3. 做中转：香港/日本中转到现有马来西亚落地。
4. 调协议和 MTU：只能改善一部分。

#### 推荐方案

优先换香港或日本东京优化线路。如果预算有限，先测试日本东京或新加坡。只靠协议调整无法把普通线路变成商用优化线路。

<a id="section-为什么商用节点比自建更快"></a>
### 为什么商用节点比自建更快？

#### 目标与约束

- **目标：** 判断是否值得继续优化自建节点。
- **约束：** 自建普通 VPS 只有一台服务器和一条普通国际线路。

#### 结论

商用节点通常快在线路、中转、带宽池和调度能力。常见商用链路可能是：

```text
用户 -> 国内/香港入口或专线中转 -> 海外落地 -> 目标网站
```

当前自建链路更接近：

```text
用户 -> 普通国际线路 -> 马来西亚 Hostinger -> 目标网站
```

因此，如果目标是接近商用体验，应优先改线路和中转，不是只换协议。
