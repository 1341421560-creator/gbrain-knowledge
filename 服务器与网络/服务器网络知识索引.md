## 1. 核心结论

- 下表按用途区分马来西亚工程服务器、日本代理节点和 64.83.43.228 远程浏览器服务器。
- 马来西亚 Hostinger 工程服务器公网 IP 是 187.127.123.84，主要承载 VNC、AmneziaWG 和 Amazon 抓取隔离环境。
- 日本代理服务器公网 IP 是 64.83.41.3，主要运行 Xray VLESS + REALITY，监听 TCP 443，并由 Clash Verge/Mihomo 使用本地 YAML 做国内直连、国外代理。
- 64.83.43.228 运行 Ubuntu 22.04、Xfce 和 Chrome。Windows 用 SSH 隧道访问 xrdp 桌面，用 WinSCP 通过 SFTP 22 端口双向传文件。
- 马来西亚服务器的 AmneziaWG 接口是 awg0、端口 51821/UDP；client1 是 10.66.66.2/32，client2 是 10.66.66.3/32。
- 日本 Xray 节点包含三个独立 UUID 用户；用户 2 原定的自动到期已取消，三位用户当前均未设置自动到期。
- Amazon 抓取必须保持服务器侧环境隔离，不使用本机浏览器、本机 Cookie、本机代理出口或 Amazon 登录账号。
- 当前本机 SSH 私钥统一使用项目根目录的 C:\Users\AI454\OneDrive\Desktop\project\server_knowlege\codex_ed25519；同内容私钥复制到新路径后，是否可用取决于 Windows 文件 ACL 是否足够收紧。
