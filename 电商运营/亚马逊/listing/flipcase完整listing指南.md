> **站点禁用词（2026-09-29 生效）：** 用户已明确要求 USA、UK Listing 避用对应站点词表中的全部词项。写作前读取[Listing 违禁词使用规则与站点索引](违禁词/listing违禁词使用规则与站点索引.md)及对应完整词表，交付前逐字段检查至零命中。本页和研究库中的历史英文示例保留为资料，复用时必须按现行词表改写。

> **使用方式：** 本文件是 FlipCase 新产品 Listing 的执行指南。收到产品后，从事实核对、榜单前排顺序学习、逐卖点 AMZ123 查词一直执行到标题五点、购物 AI 信息检查、图片/A+ 和验证交付。

## 1 使用范围、事实来源与阅读顺序

本指南用于 Amazon 翻盖、钱包及相关可拆结构手机壳的实际执行。**2026-09-24 按用户要求，重复的统计、写作规范与案例优先保留在[《FlipCase 榜单 Listing 统计与写作分析库》](flipcase榜单listing统计与写作分析库.md#scope)。**

本页保留工作流程、单款事实表、AMZ123 查词方法与历史记录、图片和 A+ 制作流程、交付核对及特定产品案例。共用研究、英文模板和验证方案通过下面各节的精确链接调用，避免两份正文各自演变。

用户已确认的要求继续生效：先学习 TOP 榜单前排的实际顺序，再按本款功能调整；每个实际卖点和通用品类分别查词，适用的高频词自然进入对应正文。2026-09-24 新增的[五点正向表达要求](flipcase榜单listing统计与写作分析库.md#positive-bullets)用于所有后续推荐稿，包括梦幻系列。

使用顺序：第 2—3 节建立本款事实；第 4—10 节按任务取用主库规则与本页查词记录；第 11—12 节处理图片、交付和验证；第 13—17 节查历史实例与来源。原目录与稳定锚点保留。历史型号、参数、排名和资料核验日期保持原范围，本次整理未刷新平台政策或关键词。

<a id="workflow"></a>
## 2 从收到产品到完成 Listing 的完整步骤

| 步骤 | 主要工作 | 完成标志 |
| --- | --- | --- |
| 1 确定范围 | 明确产品、变体、市场、语言、现有文案与拟修改字段；读取 USA 或 UK 对应完整禁用词表 | 本次范围与资料清单明确，站点词表已选定 |
| 2 核实事实 | 核对结构、功能、附件、参数和使用条件，标注依据 | 有事实表和关键待核项 |
| 3 学习榜单前排 | 优先查看既有榜单第 1—10 名的实际顺序，选结构和用途相近的样本 | 有可回查的参考名次、品牌和原顺序 |
| 4 排出本款五点 | 以适用的前排顺序为起点，将本款真实功能对应进去；必要时合并或替换主题，突出真实功能与用途 | 五条主题顺序确定，必要调整有简短理由 |
| 5 逐卖点查词 | 对每条涉及的实际卖点分别查词，再补查准确通用品类词 | 每个卖点与通用词均有查询状态 |
| 6 筛词和落位 | 从适用词中参考热度，选择能自然表达本款功能的词，放入对应卖点 | 采用词能追溯到原始指标和实际句子 |
| 7 编写文案 | 按当前规则写标题、可用 Highlights 与五点，补任务要求的其他字段 | 有自然、事实一致、顺序有榜单依据的草稿 |
| 8 核对交付 | 检查事实、型号、条件、词句、字段和图文一致性；对照站点禁用词表逐字段复查 | 对应词表零命中，交付正文、简短排序依据、选词落位与待核项 |
| 9 观察迭代 | 区分新建与已有 Listing，记录版本及搜索/AI 观察 | 用实际结果检验改动，不用单次排名判因果 |

卖点分析由执行者完成，常规交付无需长篇展示推理。排序依据可以用一句话说明“参考第几名的哪种顺序，因本款什么事实调整了哪一条”。查词或编写发现事实缺口时回到核实步骤；调整条目顺序时保持关键词与对应功能的联系。

<a id="task-card"></a>
### 2.1 单款执行工作表与交付清单

以下为每次任务可复用的工作表。过程记录与最终正文分开；已有同一事实或查词记录时使用标识引用，不重复抄写。

| 工作项 | 本次填写内容 | 完成要求 |
| --- | --- | --- |
| 任务范围 | SKU、准确手机型号、站点、语言、拟写字段、版本日期 | 不混用父体、其他型号或另一套配置 |
| 产品事实 | 事实标识、内容/数值、部件、状态、来源和确认情况 | 关键未知项单列；选用句子均有事实依据 |
| 榜单参照 | 前排名次/品牌、原五点顺序、与本款相似处 | 必须实际查看参考内容，不能只声称“参考 TOP” |
| 本款五点 | 第 1—5 条主题、对应事实、使用收益；条件另记内部事实表 | 沿用或调整榜单顺序的理由简短明确 |
| 查询覆盖 | 每个实际卖点的查询词、通用词、查询状态与查看范围 | 无结果或无适用词如实记录，不强凑 |
| 选词落位 | 原词/热度指标、采用理由、实际写法、对应条目 | 高频词自然进入适合的卖点，不孤立列词 |
| 字段核验 | 规则核验日期、标题/Highlights/五点可用字段和长度要求 | 公告要求与账户实际可用性分开记录 |
| 文案交付 | 英文标题、Highlights（适用时）、五点及任务要求字段 | 上线稿无占位符、待核数字或内部备注 |
| 禁用词复核 | 站点、完整词表版本、检查字段、命中项和改写结果 | USA 68 项或 UK 68 项全量复核（词库版本 2026-10-13），最终零命中 |
| 复核与后续 | 图文一致、版本、待核项、搜索/AI 观察安排 | 新建商品与已有商品采用适合的验证方式 |

**常规交付顺序：** 先给可使用的英文正文，再给中文简释、榜单排序依据与关键词落位表，最后列确实影响本次交付的待核项。无需展示冗长的卖点分析，也不另建多个知识库 MD。

排序与落位可以合为一张简表：`条目位置｜主题｜参考名次/原位置｜采用的已查词｜实际英文句子｜必要调整`。原始查询记录按第 5.3 节保留，交付时优先展示有用结果。

<a id="facts"></a>
## 3 建立本款产品事实与使用条件

事实表至少包含：对象或部件、具体事实、数值与单位、适用变体、使用状态、来源、确认日期、证据状态。证据状态区分用户确认、实测、规格资料声称、图片可见和待核验；图片能显示结构，不自动证明性能。

区分数量、容量和条件：部件数量不直接等于最大装载量；材料名称不自动证明耐用或防护等级；配件接口不等于包装内附送配件；局部部件能力不自动适用于整套商品。比较性、极限性和绝对性表述需要相应依据。

每个候选卖点用一句话回答：**买家有什么问题，本产品用什么真实事实回答，对使用有什么意义，成立需要什么条件？** 价值可以是完成主要任务、降低操作成本、解决适配问题、提供具体容量或改善某种使用方式，不必都写成性能优势。

缺少依据时标为内部待核项，继续处理已确定内容。影响适配、使用安全或核心购买判断的关键事实不能靠猜测补齐；需要进一步确认或测试后才能形成对应承诺。

事实表用于内部核验。推荐五点采用[主库正向表达要求](flipcase榜单listing统计与写作分析库.md#positive-bullets)；核验备注与对外五点分开，事实状态本身不因措辞偏好改变。

<a id="fit"></a>
### 3.1 型号与变体适配

记录壳品牌、手机品牌、完整手机型号、必要的型号代码、壳体变体及包装配置。屏幕尺寸或发布年份可以辅助辨认，不能单独证明适配；外观相似、系列名称接近也不能作为共用壳体的依据。

检查镜头开孔、按键、接口、装入后的贴合及开合状态；需要精确判断时使用本款资料、适配表或实物验证。某型号有地区或版本差异时，按本款证据记录，不能自行合并。写多个兼容型号前逐一确认；颜色不同不自动证明其他规格和附件完全一致。

型号字段、标题、五点、变体名称、图片中的手机和镜头开孔需要对应。用户在一个产品任务中确认的事实只适用于其明确范围。例如标准 S26 的事实不能自动移植到 S26 Ultra 或 S25；原始边界见 [钱包壳案例](#s26-boundaries)。

<a id="states"></a>
### 3.2 部件、充电、装载、闭合和附件状态

手机壳描述必须说明“哪个对象，在什么状态下，能完成什么”。尤其要区分整套产品、可拆内壳、外部钱包、磁扣、磁吸结构、支架及随附带。

| 核对主题 | 要记录的事实 | 常见误写或遗漏 |
| --- | --- | --- |
| 壳体与材料 | 外层、内壳及其他部件的真实材料和结构 | 将 PU leather 写成 genuine leather；用一处材料代表所有部件 |
| 无线充电 | 被测手机与充电方式、壳的拆装状态、装卡状态、实际结果及限制 | 只写支持充电，却不说明要拆下哪个部件 |
| 磁吸与闭合 | 磁扣的闭合用途；磁吸配件或充电兼容的具体对象和状态 | 用 magnetic closure 代替 MagSafe compatibility；将吸附直接解释为可充电 |
| 保护结构 | 对应屏幕、镜头、边角或其他部位的实际结构；尺寸的对象、单位及状态 | 把 raised edges 写成防止一切损坏；未测试就给跌落高度或认证 |
| 支架 | 支撑对象、展开方式、横竖方向及验证条件 | 横屏款写成双方向；没有依据就写任意角度 |
| 附件与连接 | 腕带、肩带、挂绳等是否随附、可否拆卸、实际连接位置 | 有挂孔写成附送带；腕带写成肩带；把携带便利写成绝不掉落 |
| 钱包收纳 | 槽位、透明窗、现金夹层、实测装载及闭合状态 | 槽位数等同任意厚卡容量；未确认透明窗是否计入总数 |
| RFID | 声称针对的材料或区域、资料或测试依据、适用条件及未知项 | 把材料名称扩展为全面防盗或所有卡片的防护保证 |
| 折叠与拆装 | 哪些部分可拆、开合与折叠状态、相关部件关系 | 将其他型号的铰链、笔位或外屏结构直接复制 |
| 尺寸与重量 | 测量对象、是否含手机和附件、空载或装载状态、单位 | 空壳重量写成整套重量；忽略装卡后的厚度变化 |

对充电、磁吸、收纳闭合等状态相关卖点，使用以下记录格式：

| 事实标识 | 目标 SKU/型号 | 对象或部件 | 使用状态/装载 | 核对问题 | 依据与日期 | 结果或未知项 | 文案位置 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 本款自定 | 本款准确对象 | 整套/具体部件 | 按实物填写 | 能否完成某动作 | 用户确认/资料/实测 | 已确认/待核验/不适用 | 标题/对应五点/属性/图文 |

该表用于梳理与验证，不是统一性能测试标准。对高频性能声明仍需与其范围相称的证据。

<a id="claims"></a>
### 3.3 性能、材料与证据边界

按 [通用事实记录方法](#facts) 区分用户确认、实测、规格资料声称、图片可见和待核验。图片可用于核对可见形态，不能单凭画面证明抗黄变、防指纹、防摔、RFID 效果或磁力强度。

保护、耐用、充电、材料或工艺描述只写依据支持的范围。无法证实的参数保留在内部待核清单；不能因为竞品写过或买家会提问就补造。无依据的性能承诺删减后，可保留真实可见的材料、部件和操作事实。

<a id="keyword-selection"></a>
### 5.2 高频词按真实功能筛选，自然埋入对应卖点

**查到与本款功能相符的高频词，可以自然埋入对应卖点。** 不要求整句与热搜词完全相同，也不要求描述腕带、支架、卡夹等部件的词必须是整件手机壳的品类词。

例如，`phone wrist strap` 是第 13.2 节 AMZ123 历史实查所得的高排名词：记录页面更新时间为 2026-09-19，本周/上周排名 5,033/4,831。这是当时的需求排名记录，不是本次新查到的实时值或绝对搜索次数。若本款附带可拆腕带，便可自然写入腕带卖点：`Includes a detachable phone wrist strap for carrying the case around your wrist.` 不应仅因该词也可用于独立腕带商品而排除它。

| 查到的候选词与本款的关系 | 采用方式 | 判断例子 |
| --- | --- | --- |
| 准确描述整件商品 | 按需要用于标题、主题标签或正文 | 钱包手机壳可用 wallet phone case |
| 准确描述已有功能、部件或随附附件 | 自然放入对应卖点，句子写清与本品关系 | 随附腕带可写 includes a phone wrist strap；翻盖形成支架可说明其 kickstand 功能 |
| 只有部分字词相同，实际需求不符 | 不采用该词组，改查更贴近的表达 | 普通腕带不能借用健身腕带、相机背带等不符用途 |
| 指向不存在或未随附的东西 | 不纳入五点关键词卖点，作为内部适用性记录 | 未随附腕带不能写 includes；磁扣不能推出支持 MagSafe |
| 型号、材料、结构或能力尚待确认 | 先留作待核候选，确认后决定 | 标准 S26 不借用 Ultra 的流量词 |

多个词均适用时，依次检查：**事实与完整购买意图是否匹配 → 在同市场、同口径下的需求表现 → 能否自然写入并增加有效信息**。高频且贴近卖点的词优先考虑；不要为了保留高排名宽泛词而改变意思。将候选标为“采用、适用但暂不放入、有待核验、不采用”，理由简短明确。

同义或近义词先归并需求，例如 wallet phone case、phone wallet case、phone case with card holder 都可能适用。选择顺口的主表达；另一个词组能补足品类或收纳信息时，可以在相应句子使用，不必所有变体集中重复，也不设每条必须几个词的配额。相关的高频词能自然表达时应积极采用，不能因任意分类而排除。

结果过宽时按看到的内容继续查“功能/部件＋品类”，必要时调整自然词序或单复数；结果为空也可换表达。明确查看范围，不能把第一页当完整词库。完成每个卖点和通用词的查询、筛选、落位后即可结束本轮；有明确新需求缺口再扩查，不为凑数量无限搜索。

错误型号、其他卖家品牌、不符用途或本品没有的能力排除。手机品牌作为真实兼容对象可以使用。未支持或未证实的功能不作为五点关键词；相关事实留在内部核验记录，必要时在适当说明位置准确处理。记录规则见[查询证据字段](#keyword-records)。

<a id="keyword-records"></a>
### 5.3 查询证据、排名口径与采用记录

关键词表至少记录：`卖点标识/通用词｜查询词｜候选原词｜市场｜访问日期｜页面更新时间｜统计期间｜原始指标及数值｜查看范围｜产品事实依据｜采用状态与理由｜实际写入形式｜字段/条目/句子｜来源链接`。

热搜排名不是搜索次数、商品自然位置、竞争难度或转化率；更新时间不等于统计周起止。缺失字段写“未显示”，上周为 0 时不自行解释为零搜索。切换查询后确认结果已更新；页面不可用、未查询、未返回结果和未找到适用词分别记录。

原词、实际写入形式和事实描述要分清：为语法调整词序、单复数或连字符后，原排名仍只属于原查询词。未查到但准确必要的事实表达可以写入，不称为已查高频词。历史案例中的排名只作方法演示；新任务核对目标产品、市场及采集日期。调用 wallet-folio-listing 时，依其缓存规则复用未满 15 天的完整有效缓存；超期、不完整或市场不符时重新查询，不能把旧数据标成当天新查。

<a id="keyword-placement"></a>
### 5.4 将原词对应到实际字段和句子

保留“事实标识 → 卖点 → 查询原词及指标 → 采用理由 → 实际写入形式 → 字段/条目/句子”的追踪关系。五点顺序按榜单参照调整后，关键词跟着对应功能移动。

型号词自然进入适配说明，收纳词进入 Cards and Cash，RFID 词进入相应卡片功能说明，腕带词进入 Wrist Strap；具体主题随本款改变。通用品类词如 phone case、wallet case 可作为自然主语补充，不必另占一条。

例如，确认本款随附可拆腕带后：`Phone wrist strap: Includes a detachable phone wrist strap for carrying the case around your wrist.` 标签与正文可按整套文案删减重复，也可写为 `Easy carrying: Includes a detachable phone wrist strap for carrying the case around your wrist.` 这两个版本展示同一已查词的自然落位，不承诺防掉落。

已查到、相关且能自然写入的高频词应优先考虑。某条没有适用热搜词时仍写清必要事实，不能强凑；准确的未查热度表达可以使用，但不能标为“已查高频词”。记录原词及实际写法；调整语序、单复数或连字符后，原排名不自动属于改写后的新词组。

字段分工见[字段表](#fields)。历史排名只属于记录中的原词、市场和时间；新任务按本款核对查询覆盖与有效缓存，不复制 S26 词表为固定必埋清单。

## 11 主图、附图与 A+：共用事实，按确认流程制作

本节完整纳入既有图像制作方法。当前文案与图像都使用本款事实、买家问题和关键词表达；图片数量、尺寸、颜色和分镜按任务确定。仅写文字 Listing 时，不触发图片制作确认节点。

<a id="visual-1"></a>
### 11.1 Listing 主图与 A+ 的适用范围和用户约定

**用户长期约定（2026-09-21）：所有产品的主图、Listing 附图和 A+，先在对话中展示并确认整体风格、分镜、画面规划和图文内容，再执行制作。**

先区分平台首图、附图和 A+：共用产品事实及品牌规范，各按版位要求设计。执行和发布前核验平台规则；[亚马逊商品图片说明](https://sell.amazon.com/blog/product-photos)与[A+ 设计指南](https://sell.amazon.com/blog/a-plus-content-design-guide)作为官方入口。

分镜文件不能替代生成前在对话中展示。“做完整的一套”“做一版看看”不等于批准未展示的规划；既有明确批准在适用条件不变时继续有效。

本章维护 FlipCase 图片制作流程；更深入的品牌视觉、光影和材质方法可按需引用其他图像主题知识。

<a id="visual-2"></a>
### 11.2 九步完整流程

**产品素材 → 产品事实与购买理由 → 卖点分镜 → 整页规划与风格 → 视觉描述稿 → 提示词整理 → 样图验证 → 批量制作 → 验收交付。**

| 阶段 | 工作与输出 |
|---|---|
| 1. 产品素材 | 查看本款原图、多角度、颜色、结构、附件、品牌、主图和五点；列出缺口。区分本款事实图、跨型号细节图、竞品图的职责。展示实际选取的竞品来源、选择理由、借鉴点与结构差异。 |
| 2. 产品事实与购买理由 | 记录型号、颜色、结构、容量、材质、功能、附件及依据，区分原图可见、用户确认、文档依据、待核对项。建立“事实 → 买家好处 → 情境/展示方式 → 可见证据”，与主图及五点核对，集中确认真实性冲突。 |
| 3. 卖点分镜 | 每张一个主要任务：购买疑虑、场景选择理由、产品状态、人物动作、可见卖点。列出精确图内短文案、中文含义和必要图外说明；不补造品牌或参数。 |
| 4. 整页规划与风格 | 先排信息顺序，再提出风格及依据；统一色板、背景材质、光线、产品尺度、字体、细节框和节奏。连续 A+ 规划相邻边缘、亮度、景深和构图过渡；多版本保留相同事实与核心内容。 |
| 5. 视觉描述稿 | 按审阅卡写清状态、动作、空间、机位、视线、光影、材质、焦点、留白和锁定项；连同前四步在对话中展示，进入 G1。 |
| 6. 提示词整理 | G1 通过后，检索与镜头相关的知识库片段，将视觉描述转为提示词；检查含糊、重复、冲突、遮挡、材质归属和事实，绑定批准的分镜版本。 |
| 7. 样图验证 | 先做风格首屏/主视觉和结构或动作最复杂的功能图，说明选片理由；展示样图、对应规划和偏差，进入 G2。多版本先各做代表样图。 |
| 8. 批量制作 | G2 通过后扩展批准范围，逐张核对事实、风格、动作、材质、文字和衔接，记录候选、修正与选用原因；方案变化按回退规则处理。 |
| 9. 验收交付 | 核对卖点覆盖、事实和五点一致性、动作融合、文字、整页、移动端及规格；交付成图、长页、替代文字、事实表、分镜、视觉描述、提示词和验收记录。 |

购买理由要转为可见证据：腕带展示佩戴与连接；卡槽和现金夹层展示收纳、取用及真实装载下的闭合。尺寸、颜色、张数、市场和语言按任务确定，不固化为 S25 参数。

<a id="visual-3"></a>
### 11.3 两个人工确认节点与状态记录

| 节点 | 用户必须看到的内容 | 通过后的动作 |
|---|---|---|
| G1 产品理解与完整规划确认 | 产品事实及缺口、参考图职责与竞品对照、整体风格、全部分镜、画面规划、准确图内文案及中文含义、必要图外说明、视觉描述和连续性安排 | 记录用户批准的版本与范围，才进入提示词整理和样图生成 |
| G2 代表性样图确认 | 样图与对应分镜、风格/结构/动作检查、已知偏差、后续整套扩展方式 | 记录样图批准范围，才批量制作 |

状态依次为：规划中 → 规划待确认 → 规划已确认 → 样图待确认 → 样图已确认 → 批量制作 → 待验收 → 已交付。

确认记录包含版本、模块范围、反馈、日期、未解决项。以用户对已展示方案的明确同意为准；沉默、等待、文件生成或一般授权不能代替确认。部分批准仅覆盖对应模块；条件不变时不重复确认。

问题集中展示；素材检查、文件整理和批准范围内的执行由 agent 推进。风格、卖点、文案或镜头发生实质变化时，重新确认受影响范围。

<a id="visual-4"></a>
### 11.4 分镜、图文内容与视觉描述模板

每张审阅卡回答：为什么拍、怎么拍、文字说什么、怎样验收。

| 固定字段 | 应说明的内容 |
|---|---|
| 编号、用途与主要任务 | 首图/附图/A+；要回答的购买问题；本张主要卖点 |
| 产品事实与购买理由 | 可验证依据、对买家的好处、必须露出的视觉证据 |
| 参考图职责 | 本款外观、结构、细节、构图、光影分别由哪张图提供 |
| 整体风格与画面规划 | 色板、背景、主体占比、构图、景别机位、人物/道具及文字安全区 |
| 图文内容 | 精确图内短文案、中文含义、图外说明草稿、文案与产品事实的对应关系 |
| 视觉描述 | 主体状态、动作进行到哪一步、前后/接触/遮挡、视线方向、光源与阴影、各部件材质、焦点与景深 |
| 连续性与不可变项 | 与上下模块的衔接；数量、结构、配色、文字和连接方式等锁定项 |
| 验收与状态 | 可观察的通过条件、当前版本、待确认/已批准及反馈 |

示例视觉描述：

> 横向取卡消费图：展开的青绿钱包壳在中央偏左，卡槽、透明窗、现金夹层朝镜头。一手托底，另一手抽卡，卡片部分留在槽内，手指不挡结构。付款终端在右后方。左上柔光照亮皮纹、缝线与手部，接触阴影自然；收纳和动作清楚，背景微虚，右上留标题区。数量、入口、配色和扣位以本款原图为准。

A+ 以图片为主，短文案放在留白，不挡商品和动作。小圆圈/方框的数量、大小、位置纳入规划；图内文案、模块正文、替代文字分别编写。[亚马逊官方 A+ 指南](https://m.media-amazon.com/images/G/35/sp-marketing-toolkit/Sellerfacingguides/A_Content_Guide_.pdf)建议减少嵌入图片的文字、使用描述性 alt-text，并用具体信息解释功能与结构；平台界面与规格在执行时核验。

<a id="visual-5"></a>
### 11.5 知识库检索与提示词整理

按已批准的视觉问题分别检索：参考图与提示词结构查[生图基础提示词与参考图工作流](../../../人工智能/图像生成/生图基础提示词与参考图工作流.md#reference-roles)，光影构图查[电商图光影构图与场景合成](../../../人工智能/图像生成/电商图光影构图与场景合成.md)，动作、材质和空间一致性查[材质人物场景与一致性控制](../../../人工智能/图像生成/材质人物场景与一致性控制.md#complex-materials)。采用过滤后的相关 chunk，说明方法对应哪个镜头。

提示词分为：整套共用要求、单张画面要求、本次修正要求。单张组织顺序为：

**任务动作 → 参考图职责 → 主体事实 → 场景与动作 → 空间和构图 → 光影 → 材质 → 风格与镜头 → 精确文字 → 输出规格 → 不可变约束 → 验收要求。**

生成前检查：

- 动作能否在一个静态瞬间成立，左右指的是画面方位还是人物自身肢体。
- 人物、道具、细节框和文字是否遮住卖点；支撑、接触、佩戴与视线是否合理。
- 皮革、TPU、金属、织物等词是否作用于正确部件，光源和阴影是否一致。
- 主图、五点、A+、图内文案和图外说明是否一致。
- 冲突按产品身份与结构、关键材质、空间关系、光影、风格装饰的顺序处理。
- JSON 和字段表只组织要求；模型名称、种子、参考权重等只记录工具真实支持和可核验的信息。

**每次默认以用户原始参考图为基础生成或修正，不把 AI 生成结果反复输入模型。只有用户明确指定某张生成图作为修改对象时，才允许使用该生成图。** 已确认风格通过文字规范、原始参考与人工比对维持；写入提示词的约束仍须在成图中检查。

<a id="visual-6"></a>
### 11.6 镜头被否定后的重设计与生成纠错

| 反馈类型 | 返回的位置 | 必须交付的修订 |
|---|---|---|
| 用户否定场景、镜头、构图、图文内容或整体风格 | 卖点分镜/整页规划/视觉描述 | 说明被否定原因，重新设计景别、机位、动作、空间或叙事方式，展示新版方案和文案；用户确认后才整理提示词 |
| 规划已批准，但生成图出现结构、手部、朝向、遮挡、文字或光影错误 | 提示词与生成验证 | 保留批准的意图，记录错误位置、改变内容、保持内容和通过条件，基于原始素材重新生成并检查 |
| 用户改变产品事实、卖点或适用范围 | 产品事实与相关分镜 | 更新依据及一致性表，识别受影响模块，集中重新确认 |
| 已批准内容仅需尺寸/格式导出 | 导出与文件验收 | 保持批准构图和主体比例，检查裁切、压缩、色彩与文件规格；若必须改变构图则回到规划 |

镜头被否定后，应说明新版改变了哪些景别、动作或空间关系，必要时提供不同方案；不能只添加“更高级、更自然”或反复生成被否定的方案。

修订记录：原方案版本 → 用户反馈 → 原因判断 → 新镜头或纠错指令 → 保留项 → 受影响模块 → 人工确认 → 样图与验收结果。

<a id="visual-7"></a>
### 11.7 连续性、验收与交付

逐张规划上下边缘，统一背景材质、亮度、色温、光向、景深和阅读动线；验收同时查看单张与长页。**零间距拼接不等于视觉连续；没有补色条也不代表场景衔接已经通过。** 有断层则回到构图或背景规划修正，不能用白边、色条或横线凑尺寸。

验收四组：

1. 事实与覆盖：型号、颜色、品牌、容量、材料、结构、附件、功能及主图/五点/A+ 一致；每个要求都有可见证据。
2. 动作与融合：左右肢体、视线、朝向、接触、支撑、重力、透视、尺度、遮挡和阴影合理。
3. 视觉与文字：主体突出、材质可辨，文案准确并不遮挡关键内容，细节窗适度，缩小后仍能理解。
4. 整页与文件：风格及上下衔接通过，比例和尺寸正确，不拉伸产品、不补色条；移动端和实际模块裁切可用。

交付单张、整页预览、描述性 alt-text，以及事实表、分镜、视觉描述、实际提示词、参考职责、确认和验收记录。纯背景、无文字及额外规格在任务开始时约定；原稿、修正版、最终文件分别标识，未批准样图不能记为交付完成。

### 11.8 钱包壳原稿的八张 Listing 图片安排

Word 的顺序是一套让重要答案容易找到的设计方案，不是平台排序要求。区分第一张平台首图与后续附图。

| 图片 | 信息任务 | 需要展示的证据 |
| --- | --- | --- |
| 1 | 快速识别商品与点击选择 | 原文拟沿用多角度主图方向；发布前核对对应首图规范与缩略图可读性 |
| 2 | 真实收纳与闭合 | 卡片、现金、内页布局及真实装载后的闭合状态 |
| 3 | RFID 材料与功能 | 经确认的层名、层序及功能边界；示意不能替代测试 |
| 4 | 支架与腕带 | 折叠状态、观看方向、腕带佩戴与连接方式 |
| 5 | 厚度与携带 | 装卡后是否鼓起、口袋或手持状态，保持真实装载 |
| 6 | 做工细节 | 卡槽、缝线、开孔、PU 和 TPU 结构对应关系 |
