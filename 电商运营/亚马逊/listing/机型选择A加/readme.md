<a id="entry-points"></a>
## 通用素材

| 需要什么 | 入口 |
| --- | --- |
| 手机独立正面／背面、组合图、真实尺寸、镜头与前屏结构、去Logo及SKU边界 | [机身与型号素材](通用素材/手机机身/使用说明.md) |
| 对应机型与系统的真实设置页面、字段判断和缺项 | [真实设置页面](通用素材/设置页面/使用说明.md) |
| 开始制作、阻断条件与发布验收 | [制作与验收](通用流程/制作与验收.md) |

机身同图统一毫米比例，教程屏幕展示大小另由店铺决定。当前登记49款独立背面、4款三星正背面组合，不能称正反面齐全；校准、Logo和来源状态分别看索引。

设置页以“机型＋有证据的系统版本”选择。系统未知、结果空白或仅昵称不默认用于新教程；不改写另一型号的画面冒充真实结果。

## 店铺模板

| 店铺 | 当前选择 |
| --- | --- |
| [JHWVVTF](店铺模板/JHWVVTF/版式说明.md) | J01单型号四宫格、J02合并单机身、J03合并多机身 |
| [moment](店铺模板/moment/版式说明.md) | iPhone四步、三星三步普通A+ |

店铺 → 变体 → 规格 → 当前修订。缺少店铺或规格先确认／列缺，禁止借另一店铺模板，也不将普通版缩图当作已确认移动版。视觉参考与真实截图、发布通过分别判断。

## 取用与维护

先确认本次壳款／SKU和兼容组，再查素材证据并选本店铺模板。外观相近不等于共壳，组内可只选一台代表机做教程。

原图、发布处理版和示意分别标记。最终图片按目标站点检查Logo和可辨认文字，旧词表结论不跨修订继承。当前型号、素材和来源由各权威JSON索引维护，正文不重复抄录整张型号表。
