## 可复核的方法、数据字典和限制

<a id="method-extraction"></a>
### 提取与去重方法

1. 只读取`标题亮点和五点/标题亮点和五点.txt`的100个文件；品牌故事文案、QA和图片文字不加入标题或五点词频。
2. 按独立行标题切分ASIN、站点、标题、标题下亮点、About this item五点。空亮点保持空，不让下一节被误当成亮点；原始正文另保留。
3. 以外部`1.`等编号分段；段落内部的`(1)`、`1.`列表作为同一条内容，不拆成多个五点。Defencase段内重复数字同样保留。
4. 用站点+ASIN去重；三对三字段完全一致，按最前记录保留代表；所有来源在100行表和原文快照仍可定位。

<a id="method-metrics"></a>
### 长度、匹配和人工编码方法

| 字段/指标 | 定义 |
| --- | --- |
| id/rank | 原文件夹和前缀数字；不是重新核验的实时排名 |
| source_relative/sha256 | 相对原目录的路径与原文件字节哈希 |
| title/highlights/bullets | 去首尾空白后的正文；段内原词、标点和编号保留 |
| identity_source | 文本自身或商品清单，不把恢复字段说成原文自带 |
| representative/aliases | 同ASIN代表和来源别名；不删除原记录 |
| form | 结合首图与文字的主结构分类，按本研究定义互斥 |
| primary_order | 每条主要购买任务人工编码；复合段选主任务，原文供复核 |
| 字符长度 | Python len，含空格/标点，不含字段名、外部编号 |
| 词项长度 | 字母数字串，允许内部撇号、连字符；不会把它说成后台字符规则 |
| 概念覆盖 | 固定正则词组匹配，单商品单字段至多1次；详见配置文件 |
| 精确词频 | 小写字母词、单复数不归并，停用词公开保存在脚本 |
| 品牌覆盖 | 有至少1个样本命中词组的品牌标签数；不是品牌支持该功能的认证 |
| 功能支持计数 | 另按完整语义人工核对对象、正否定、拆装状态；不是词频计数 |

标题75、亮点125只是本批观察阈值，分析不证明平台字段限制。`RFID`并不自动命中拼错的`Bolcking`之外的缺词，也不把DATA blocking自动并入RFID。可拆宽口径会命中remove phone case、removable wrist strap，所以功能结论改看人工状态表。支架pattern匹配stand/kickstand，不保证覆盖全部同义表达；保护、场景等概念表也有词组边界，不能说捕捉了全部语义。

<a id="method-limits"></a>
### 缺失样本与因果边界

94个钱包样本中包括69号仅1段和8份空亮点，所以功能未写到只能标记没有观察到该表述。首条统计保留94，第二条93，段落风格467；完整组有90组5条、2组6条，另1组4条、1组1条。若后续研究只比较完整5条，应重算分母，不能沿用本页比例。

没有销量/广告/转化的受控数据，不能将高频顺序、长度或词汇推导为排名原因。同品牌复用、历史批次、机型与结构差异会影响分布。本次不核验手机型号发布时间、不登录后台、不核验当前规则、不验证认证、RFID距离、频段、材料实物或防摔结果。
