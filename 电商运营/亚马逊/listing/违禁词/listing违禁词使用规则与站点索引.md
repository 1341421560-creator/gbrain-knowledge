## 1 当前执行规则

**自 2026-09-29 起，根据用户本次明确要求，编写或检查手机壳 Listing 时，USA 使用 USA 词表，UK 使用 UK 词表，最终文案不得出现对应站点的禁用词、词组及本页规定的相近词形。** 本规则是用户设定的内部写作约束。

用户原话：“把这个整理然后放到知识库中，写listing不允许出现里面的词 分USA站点和UK站点”。

检查范围覆盖本次任务实际编写的标题、五点及其小标题、商品描述、Highlights、A+ 文案、Listing 图片上的文案、变体文案和后台搜索词。词频、搜索热度、竞品写法和知识库旧示例均不能覆盖本规则。发现命中后按用户授权范围处理；用户提供的原稿不得直接覆盖或擅自重写，具体执行见[用户文案保真与修改授权](#copy-integrity)。最终复核同时包含原词和相近词形，不得仅通过改变大小写或词形规避。

2026-09-22 的旧记录曾将同一词表仅作为待核验资料。**本次用户要求更新了运营执行状态，以本页及分站词表为准。** 商标登记、权利状态及平台政策仍未在本次任务中核验，原表标题中的“已注册商标”只作为来源原文保存。

## 3 词条整理与匹配口径

以下是本次为执行禁用要求采用的文本检查口径，不是商标法律判断。

1. 原表词项逐项保留原始拼写、大小写、标点与单元格位置；另列小写检查词，按字母顺序整理。每站独立去重，保留来源。
2. 检查时忽略英文大小写，统一全角／半角和连续空白。不能用全大写、首字母大写或换行绕过禁用项。
3. 单词按完整英文词匹配。短词 `as`、`on`、`or`、`in` 等不能直接按任意子串查找：例如 `case` 中的 `as`、`phone` 中的 `on`、`for` 中的 `or` 不算独立词命中。连字符、标点和空白可形成词边界，`snap-on` 中的 `snap` 与 `on` 应命中 USA 词表。
4. 多词条目按完整连续词组检查，统一词间空白并复核连字符等标点分隔变体。`designed for` 不拆成两个独立禁用项，`liquid crystal`、`stand folio`、`take off`、`the process` 同理。
5. 原表 `dedicated.` 保留在原词列，检查词记为 `dedicated`；句末句号不用于绕过检查。
6. 原表 `WIRELESS +` 的加号具有词条意义，检查 `wireless +` 与 `wireless+`，不把它扩展成对 `wireless` 单词的单独禁用。
7. **自 2026-10-06 起，禁用词的常见单复数、词形变化及明显相近形式也要避用。** `essential` 在 USA 原表中，`essentials` 虽然不是同一字符串，仍不得用于最终文案。不能以“完整词匹配没有命中”或“词表未单列该词形”为理由放行。执行细节见[相近词形与变体避用](#word-family)。原表词项与计数仍按原始证据保存，不将衍生检查项伪装成原表记录。

<a id="word-family"></a>
### 3.1 相近词形与变体避用

**用户于 2026-10-06 明确纠正：“类似的 `essentials` 与词表里的 `essential` 不同，也不要用”。** 这是在原有完整词／词组检查之上的内部制作要求，不是新增的商标事实或亚马逊官方政策结论。

- 检查对应站点原词后，再复核常见单复数、时态、人称变化、明显派生及其他与禁词直接关联的相近词形；这些形式同样避用。明确实例为 USA 的 `essential → essentials`。
- 不通过刻意拼错、拆字、加连字符、改变大小写或换用相近词形规避。多词禁用项同时复核其连续词组和明显变体。
- **保留词边界：** 词形关联不同于任意子串匹配。`phone` 内部的 `on`、`case` 内部的 `as` 不据此算独立禁词，也不能把所有语义相关词无限扩展为禁词。
- 变体检查应能说明“成品词形 → 对应原表词项”的关系。记录原词命中和相近词形命中两类结果；2026-09-29 历史原表是 USA 68 项、UK 54 项；2026-10-13 补充后当前词库为 USA 68 项、UK 68 项。新增的 14 项有用户补充文件证据，不能用衍生检查数量改写原始来源条数。
- 只有原词精确匹配零命中，不能宣称已经通过完整检查；还须检查实际图片文字、标题、正文、Q&A、Logo 周边小字及当次其他交付字段中的相近词形。
- 无法判断某个形式是否属于相近词形时，先标明该形式和对应词项，不直接宣称通过。若它来自用户原稿，按[原稿修改授权规则](#copy-integrity)处理。

<a id="workflow"></a>
## 4 写作与复核流程

1. 明确 USA 或 UK 站点，读取对应页面的全部词组分段，核对当前清单条数：USA 68 项、UK 68 项（词库版本 2026-10-13）。知识库搜索返回的少量 chunk 不是完整词库，不能只用某个搜索片段完成全量检查。
2. 先确认原稿来源、用户已确认文案版本和允许修改的范围；仅制作或排版图片时，锁定文字原文。拟写字段、关键词和模板检查对应站点原词及相近词形；常见英语词也按内部规则避用。
3. 逐字段记录“站点、材料版本、命中原句、实际词形、对应原表词项、命中类别、是否为助手新增、处理状态”。原稿命中和助手改写导致的命中分别归因。
4. 用户已授权写作或改写时，在该授权范围内调整并复查；原稿未获修改授权时，先指出问题并给出明确候选改法，不能直接覆盖。记录原始来源版本 2026-09-29、当前词库版本 2026-10-13 和执行口径更新日期 2026-10-06。原词与相近词形均通过，才可报告本规则检查通过；替代词同时核对真实含义与语言通顺度。
5. 历史研究、竞品原文、旧样例和原词表为证据材料，保留原文；将其用于新的 Listing 时必须通过本规则。

<a id="copy-integrity"></a>
### 4.1 用户文案保真、修改授权与来源归属

**用户于 2026-10-06 明确要求：“不要随便修改我的文案”。** 用户提供或已确认的文稿是文字依据；助手后来的摘要、润色、翻译、重写版本不能冒充用户原稿。

1. 只要求设计图片、排版、换字体、改尺寸、制作轮播或检查禁词，不代表允许增删、总结、翻译、精简或改写正文。正常换行和字体布局可以执行，文字内容保持逐字一致；空间不足时先说明，不能为了排版自行改句。
2. “保留完整正文”必须明确指向用户提供或确认的文字版本，不得只保留助手后来写的摘要，却声称完整保留了用户原稿。
3. 检查时同时区分用户原稿、经授权修改稿与实际成品文字。发现禁词后指出准确句子与材料版本；助手自行新增的词应明确归因于助手，不能说成用户文案里存在该词。
4. 用户原稿触发禁词或相近词形要求时，先列出“原句、实际词形、对应禁词、建议改法”，取得针对该改法或该类文案修改的授权后再修改。会话已有明确修改授权时沿用其范围，不重复索取相同许可。
5. 允许改写时保留修改前后对照和来源；重新核对产品事实、品牌信息、原词禁用项及相近词形。成品逐字核对，不能只检查生成提示词或把 OCR 零命中当作文字保真证明。
6. 用户要求“只更新知识库、暂时不要修改图片”时，本次仅维护知识规则，不恢复原文、不重做图片、不更新轮播；待后续用户明确要求再继续制作。

**此次纠错来源：** 2026-10-06 Moment Dextrad 品牌故事制作对话。已核对用户提供的 `Moment Dextrad品牌故事.txt` 原稿没有 `our`；`our collection`、`As our collection grows, our focus…` 出自助手此前改写的卡片。错误应记录为助手擅自改稿并且未清楚说明检查对象，不能归为用户原稿问题。另一个错误是以字符串不同为由放行 `essentials`；现按上节要求避用。该实例只用于说明来源归属和操作边界，不扩展为未经核验的品牌或平台结论。

品牌故事制作同步执行[品牌故事卡片学习指南中的文案保真规则](../品牌故事/品牌故事卡片学习指南.md#copy-integrity)。
