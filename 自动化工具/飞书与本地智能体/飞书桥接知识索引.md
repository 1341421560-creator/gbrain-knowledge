<a id="core-conclusions"></a>
## 1. 核心结论

- 飞书自建应用用 WebSocket 长连接接收事件，本机作为桥接主机；关机、睡眠、断网或进程退出后需要重新启动。
- 普通推理调用本机 Codex CLI，使用本机 Codex/ChatGPT Pro 账户，不配置 OpenAI API Key。
- 每个飞书聊天窗口以 `chat_id` 隔离 Codex session、图片、附件、Base 内容和执行队列；不同窗口不会混用上下文。
- 同一窗口顺序处理，不同窗口可以并行；`/clear` 只清除当前窗口上下文。
- 图片先作为视觉上下文，只有明确修图或生图意图才调用图像工具；修图默认基于用户原图。
- 文件提取和 Base 读取按实际内容进入上下文；Base 使用消息发送者本人 OAuth，不使用本机飞书用户。

<a id="safety-maintenance"></a>
## 5. 安全与维护边界

- 不在知识库记录 App Secret、访问令牌、OAuth device code、二维码内容或具体用户 Open ID。
- Base 群聊访问被禁止；私聊授权账户必须和消息发送者一致。
- Base 当前只读。未来写入应采用变更预览和用户确认，删除或结构变更必须单独确认。
- 图像、附件和运行状态在项目 `temp/`；Codex 原始 session 位于用户目录 `.codex/sessions/`。
- 修改模型、代理、心跳、指令、队列、文件范围、图像规则或 OAuth 后，应更新本专题并重跑回归测试。
- 对话中的临时尝试和失败方案不作为当前配置；以当前代码、启动器和测试结果为准。
